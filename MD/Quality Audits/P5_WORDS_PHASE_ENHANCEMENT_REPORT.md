## 1. ملخص التحسينات

### 1.1 تحسين عرض المعنى (Single View)
- **قبل:** المعنى يظهر بحجم `--fs-sm` بدون صورة أو ترجمة صينية
- **بعد:** المعنى يظهر بحجم `--fs-md` مع:
  - إيموجي كبير كمرجع بصري (🚪🏠🌴👘🔥)
  - ترجمة صينية مع بينيين (门 mén, 房子 fángzi, 椰枣 yēzǎo, 长袍 chángpáo, 火 huǒ)
- **الحل التقني:** إنشاء ثابت `P5_WORD_META` في `app.js` (تجنّب تعديل `lesson-01.js` المجمّد)

### 1.2 شريط التاريخ (History Strip)
- **قبل:** الإيموجي في الكلمات السابقة مخفي (`display: none`)
- **بعد:** الإيموجي يظهر بحجم `1rem` كمعرّف بصري سريع

### 1.3 نقاط التقدم
- **قبل:** 12px, opacity 0.3/0.65
- **بعد:** 14px, opacity 0.35/0.7 — أوضح على البروجكتور

### 1.4 تعليمات P5
- إضافة `font-weight: 500` لتعليمة المرحلة — أوضح من بعيد

### 1.5 Quad View — مراجعة الكلمات الخمس (جديد)
- شاشة مراجعة بعد آخر كلمة تعرض البطاقات الخمس معاً
- كل بطاقة تحتوي: إيموجي + كلمة + حرف مستهدف (مع خط سفلي) + اسم الحرف + معنى + صينية + زر تشغيل صوت
- **الشبكة:** 5 أعمدة → 3 أعمدة (≤900px) → 2 أعمدة (≤600px)
- زر "التقييم السريع →" للانتقال للتقييم

### 1.6 Micro-Assessment — استمع واختر الكلمة (جديد)
- تقييم تكويني اختياري يتبع نمط P3
- Fisher-Yates shuffle لترتيب عشوائي للأسئلة
- المعلم يشغّل الصوت → الطلاب يرفعون أصابعهم (1-5) → Space يكشف الإجابة
- 5 خيارات مع رقم إصبع + إيموجي + كلمة
- زر "تخطّي التقييم ←" للتجاوز مباشرة إلى P6
- **الشبكة:** 5 أعمدة → 3 أعمدة (≤900px) → 2 أعمدة (≤600px)

## 2. التفاصيل التقنية

### 2.1 حالة التطبيق (STATE)
```
p5ViewMode: 'single' | 'quad' | 'assess'
p5AssessIndex: 0
p5AssessRevealed: false
p5AssessOrder: [] (Fisher-Yates shuffled)
```

### 2.2 تدفق المراحل
```
Single View (5 كلمات × 4 خطوات كشف)
  → آخر كلمة: زر "مراجعة الكلمات ←"
    → Quad View (5 بطاقات)
      → زر "التقييم السريع →"
        → Micro-Assessment (5 أسئلة)
          → P6
      → Space: ينتقل للتقييم
    → ← : يعود لآخر كلمة
  → ← : يعود للكلمة السابقة
```

### 2.3 التراجع (Retreat — ArrowLeft)
| الحالة | السلوك |
|--------|--------|
| assess + revealed | إخفاء الإجابة |
| assess + index > 0 | السؤال السابق |
| assess + index = 0 | العودة لـ Quad |
| quad | العودة لآخر كلمة (single, fully revealed) |
| single + revealStep > -1 | إخفاء آخر خطوة |
| single + wordIndex > 0 | الكلمة السابقة (fully revealed) |

### 2.4 الدوال الجديدة (app.js)
| الدالة | الوصف |
|--------|-------|
| `p5ShowQuad()` | تحويل الوضع إلى quad |
| `renderP5Quad(container)` | رسم شبكة البطاقات الخمس |
| `p5StartAssess()` | تهيئة التقييم (Fisher-Yates shuffle) |
| `renderP5Assess(container)` | رسم شاشة التقييم |
| `p5AssessPlay()` | تشغيل صوت الكلمة المستهدفة |
| `advanceP5Assess()` | كشف الإجابة أو الانتقال للسؤال التالي |
| `p5SkipAssess()` | تخطّي التقييم → P6 |
