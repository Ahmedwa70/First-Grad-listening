## 1. السبب التربوي

### المشكلة
النظام السابق (5 خطوات) كان يعرض الكلمة بدون معنى في الخطوة الأولى. الطالب الصيني المبتدئ في الدرس الأول لا يستطيع قراءة الكلمة — فيحدّق في شكل مجهول بدون فهم. المعنى كان آخر خطوة (step 4) بينما يجب أن يكون أول شيء يفهمه الطالب.

### الحل
نقل المعنى (إيموجي + عربي + صيني) ليظهر **مع الكلمة في الخطوة الأولى**. دمج اسم الحرف والصوت في خطوة واحدة. تقليص الخطوات من 5 إلى 4.

### المبدأ التربوي
> المعنى أولاً يعطي الطالب سبباً للاهتمام. عندما يعرف أن "نار = 🔥 火" يصبح لديه دافع لمعرفة ما هو الحرف المستهدف.

## 2. التغييرات

### 2.1 إعادة ترتيب الكشف التدريجي (5 → 4 خطوات)

| | قبل (5 خطوات) | بعد (4 خطوات) |
|--|----------------|---------------|
| Step 0 | الكلمة بدون تلوين | **الكلمة + المعنى** (إيموجي + عربي + صيني) |
| Step 1 | تمييز الحرف | تمييز الحرف (بدون تغيير) |
| Step 2 | اسم الحرف | **هوية الحرف** (اسم + صوت معاً) |
| Step 3 | الصوت | **الصوت والترديد** (تشغيل تلقائي) |
| Step 4 | المعنى | ~~حُذف — مدمج في Step 0~~ |

### 2.2 تحويل التوزيع البصري (أفقي → عمودي)

| | قبل | بعد |
|--|------|------|
| Layout | Grid أفقي 4 أعمدة | Flex عمودي مركزي |
| عرض البطاقة | `min(1300px, 95vw)` | `min(700px, 92vw)` |
| مسار العين | يقفز أفقياً بين 4 مناطق | ينزل في خط واحد |
| الفواصل | borders عمودية بين الأعمدة | لا فواصل — تدفق طبيعي |

### 2.3 دمج الاسم والصوت

| | قبل | بعد |
|--|------|------|
| Step 2 | اسم الحرف فقط (باء) | اسم + صوت معاً (باء /ب/) |
| Step 3 | صوت الحرف (/ب/) + تشغيل | تشغيل + ترديد فقط |
| السبب | الطالب المبتدئ لا يفرّق بين "اسم" و"صوت" كمفهومين منفصلين |

## 3. التفاصيل التقنية

### 3.1 app.js

| التغيير | التفصيل |
|---------|---------|
| `P5_REVEAL_STEPS` | 4 خطوات: `context`, `target`, `identity`, `audio` |
| `advanceP5()` | auto-play يعتمد على `key === 'audio'` بدل index ثابت |
| `renderP5()` | `#p5-context` يحتوي الكلمة + المعنى معاً. حُذف `#p5-meaning` كعنصر منفصل |
| `renderP5Card()` | `#p5-context` يظهر عند step ≥ 0. `name-visible` و `phoneme-visible` معاً عند step ≥ 2 |

### 3.2 css/style.css

| التغيير | التفصيل |
|---------|---------|
| `.p5-card` | `display: flex; flex-direction: column; align-items: center` بدل Grid |
| `.p5-container` | إضافة `width: 100%; align-items: center` |
| `.p5-header`, `.p5-nav` | إضافة `width: 100%` |
| Grid areas | حُذفت (`#p5-word`, `#p5-target`, `#p5-audio`, `#p5-meaning` grid-areas) |
| Responsive ≤900px | حُذف (لم يعد ضرورياً — التصميم عمودي أصلاً) |

### 3.3 HTML Structure الجديد (Single View)

```
.p5-card[data-word]
  ├── #p5-context.reveal-block     ← جديد (كان #p5-word + #p5-meaning منفصلين)
  │     ├── .p5-word-display
  │     │     └── .p5-char / .p5-target-char[--tc]
  │     └── .p5-meaning-box
  │           ├── .p5-meaning-emoji
  │           └── .p5-meaning-lines
  ├── #p5-target.reveal-block      ← بدون تغيير
  │     └── .p5-highlight-box
  └── #p5-audio.reveal-block       ← بدون تغيير
        └── .p5-play-btn + .ctrl-btn.choral
```
