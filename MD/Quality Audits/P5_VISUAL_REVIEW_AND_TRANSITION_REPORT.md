## 1. التحليل البصري

### 1.1 ملاحظات قبل التعديل

| العنصر | الملاحظة |
|--------|----------|
| بطاقة الهوية | الحرف + الاسم + الصوت مرتبة عمودياً — تبدو كـ 3 معلومات منفصلة بدل وحدة واحدة |
| انتقال الكلمات | فوري بدون حركة — يشعر الطالب بـ "استبدال شاشة" وليس "تحوّل إلى كلمة جديدة" |

3. **فواصل بصرية**: شريط رفيع بلون الحرف بين عناصر بطاقة الهوية لتأكيد الترابط

## 2. التغييرات

### 2.1 بطاقة الهوية — من عمودي إلى أفقي

**قبل:**
```
┌─────────────────┐
│  ب    باء       │
│        /ب/      │
└─────────────────┘
```

**بعد:**
```
┌─────────────────────────┐
│  /ب/  │  باء  │  ب      │
└─────────────────────────┘
```

| التغيير | التفصيل |
|---------|---------|
| Layout | من `flex-column` (`.p5-id-info`) إلى صف أفقي واحد |
| فواصل | `<span class="p5-id-sep">` — شريط 2px بلون الحرف بين العناصر |
| الحرف | أكبر قليلاً `clamp(2.2rem, 5.5vh, 3.8rem)` |
| الاسم | أكبر `clamp(1rem, 2.5vh, 1.5rem)` — ملوّن بـ 70% من لون الحرف |
| الصوت | نفس الحجم — `var(--text-secondary)` |
| كشف | الاسم والصوت يظهران بـ `translateX(8px→0)` + `opacity(0→1)` |
| الفواصل | تظهر مع الاسم (`name-visible`) |

**السبب التربوي:** الطالب المبتدئ يحتاج رؤية "شكل الحرف → اسمه → صوته" كسلسلة مترابطة — ليس كقائمة عمودية. السطر الأفقي يُقرأ كوحدة واحدة.

### 2.2 انتقال الكلمات — Premium Smooth Transition

**قبل:** `container.innerHTML = ...` — استبدال فوري بدون حركة
**بعد:** خروج ناعم (260ms) → دخول تدريجي (320ms)

| المرحلة | التأثير |
|---------|---------|
| خروج (للأمام) | `translateX(-30px) scale(0.97) opacity(0)` — 260ms |
| خروج (للخلف) | `translateX(30px) scale(0.97) opacity(0)` — 260ms |
| دخول (للأمام) | من `translateX(30px)` → `translateX(0)` — 320ms |
| دخول (للخلف) | من `translateX(-30px)` → `translateX(0)` — 320ms |

| الحماية | التفصيل |
|---------|---------|
| `_p5Transitioning` | flag يمنع الضغط المتكرر أثناء الانتقال |
| timeout 280ms | بين الخروج والدخول |
| `requestAnimationFrame` مزدوج | لضمان تطبيق class الدخول قبل إزالته |

**السبب التربوي:** الطالب يشعر بـ "الكلمة تتحول إلى كلمة جديدة" — انسياب طبيعي يحافظ على مكان العين بدل قفزة مفاجئة تفقد التركيز.

## 3. التفاصيل التقنية

### 3.1 app.js

| التغيير | التفصيل |
|---------|---------|
| `renderP5()` markup | إزالة `.p5-id-info` wrapper — العناصر الثلاثة + فاصلان في صف واحد مباشر |
| `p5TransitionWord()` | دالة جديدة — تضيف exit class → timeout → render → enter class |
| `_p5Transitioning` | guard flag يمنع التكرار |
| `advanceP5()` | يستدعي `p5TransitionWord()` بدل `renderP5()` عند تغيير الكلمة |
| `p5PrevWord()` | يستخدم نفس نظام الانتقال مع `direction='prev'` |
| Retreat handler | يستدعي `p5PrevWord()` بدل تغيير مباشر |

### 3.2 css/style.css

| التغيير | التفصيل |
|---------|---------|
| `.p5-identity-card` | `justify-content: center; gap: 0` — الفراغات تُدار بالفواصل |
| `.p5-id-sep` | `width: 2px; height: 1.6em` — فاصل رفيع ملوّن |
| `.p5-target-name` | `font-size: clamp(1rem, 2.5vh, 1.5rem)` — أكبر من `var(--fs-sm)` |
| `.p5-target-name` | لون `color-mix(in srgb, var(--lc) 70%, var(--text-primary))` |
| Reveal transition | `translateX(8px→0)` بدل `max-height(0→2em)` — أنعم |
| `.p5-exit-left/right` | أنيميشن خروج الكلمة |
| `.p5-enter-left/right` | أنيميشن دخول الكلمة |
| `.p5-card` | إضافة `transition` للـ opacity و transform |

### 3.3 Classes الجديدة

| Class | الوظيفة |
|-------|---------|
| `.p5-id-sep` | فاصل عمودي بين عناصر بطاقة الهوية |
| `.p5-exit-left` | خروج البطاقة لليسار (تقدم) |
| `.p5-exit-right` | خروج البطاقة لليمين (تراجع) |
| `.p5-enter-left` | دخول البطاقة من اليسار (تراجع) |
| `.p5-enter-right` | دخول البطاقة من اليمين (تقدم) |

### 3.4 Class محذوف

| Class | السبب |
|-------|-------|
| `.p5-id-info` | لم يعد هناك wrapper — العناصر في صف مباشر |
