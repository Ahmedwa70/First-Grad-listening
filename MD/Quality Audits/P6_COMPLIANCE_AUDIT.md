## التنفيذ الحالي — ماذا يفعل P6 فعلاً؟

P6 الحالي = **«التمييز السمعي»** بثلاث جولات: D1 (تعرّف) → D2 (نفس أم مختلف) → D3 (أصوات متقاربة).  
هذا التصميم **مُقَر بقرار QD-02** كبديل مؤقت عن سباق التعزيز.

### جولة D1 — تعرّف على الحرف

#### تشغيل الصوت قبل الكشف (الصوت أولاً) — 🟢 مكتمل

زر `p6-big-play` يشغّل الصوت عبر `AudioManager`. الإجابة مخفية حتى يضغط المعلم Space. يتبع مبدأ «الصوت أولاً».

- `js/app.js:1928`
- `md/Governance/DESIGN_PHILOSOPHY.md`

#### الكشف التدريجي (3 خطوات) — 🟢 مكتمل

خطوة 1: الحرف. خطوة 2: الاسم + الفونيم. خطوة 3: عدد الأصابع + النقاط + الحقيقة. يُدار عبر `data-reveal-step` و CSS transitions.

- `js/app.js:1846-1862`

#### ترميز الأصابع 1-4 — 🟡 جزئي

النظام يعرض «كم إصبعاً؟» ويكشف العدد الصحيح، لكن **لا يوجد مثال تدريبي** قبل أول سؤال يشرح الترميز (أي حرف = كم إصبع). مستوى A0 قد يحتاج توضيحاً بصرياً أولاً.

- `P6_AUDIT_REPORT.md §3.6`

---

### جولة D2 — نفس أم مختلف؟

#### مقارنة صوتين وكشف النتيجة — 🟢 مكتمل

زرّا صوت مستقلان + سؤال + كشف «= نفس الصوت» أو «≠ صوتان مختلفان» مع عرض الحرفين عند الاختلاف. 6 أزواج (3 متماثلة + 3 مختلفة).

- `js/app.js:1938-1957`
- `js/lesson-01.js:220-233`

#### D2 Activity State Machine — 🟢 مكتمل

آلة حالة `p6EnsureD2Activity()` تدير الانتقالات: INITIAL → REVEALED → NEXT. مع `p6ObserveD2Response()` و `p6DisposeD2Activity()`.

- `js/app.js:1766-1806`

---

### جولة D3 — الأصوات المتقاربة

#### عرض مجموعة أصوات متقاربة — 🟡 جزئي

مجموعتان فقط: (ب/ت/ث) و(ب/ن). الحروف **ظاهرة بصرياً أثناء المقارنة** — قد يعتمد الطالب على الشكل بدل السمع. كما أن العدد محدود (2 فقط).

- `js/lesson-01.js:234-243`
- `P6_AUDIT_REPORT.md §3.2`

### تجربة المعلم

#### تلميح المعلم (P6_GUIDES) — 🟢 مكتمل

شريط «للمعلم» يعرض: الغرض + الخطوة الحالية (تمييز الصوت / مقارنة صوتين / تمييز المتقاربة) مع حالات «الإجابة ظاهرة». يتحدث عبر `updateHint()`.

- `js/app.js:1700-1715`

#### التنقل بلوحة المفاتيح — 🟢 مكتمل

Space = كشف/تقدم. ← = تراجع. A = انتباه. يتبع القاعدة 3.

- `js/app.js:243` (advance switch)
- `ARCHITECTURE_RULES.md:75`

#### القفز بين الجولات — 🟡 جزئي

أزرار D1/D2/D3 تسمح بالقفز الحر عبر `p6GoRound(i)`. لكن **لا توجد حماية تربوية** تمنع القفز قبل إتمام الجولة السابقة.

- `js/app.js:2022-2028`

#### تسجيل أداء الطلاب / ملاحظات المعلم — 🔴 مفقود

لا يوجد `studentAnswer` أو `p6Scores` أو أي آلية لتسجيل من أجاب صح/خطأ. المعلم لا يعرف أين تعثر الصف. مقارنة: P7 يحتوي `p7Scores` + أزرار تقييم (ممتاز/جيد/يحتاج مراجعة).

- `P6_AUDIT_REPORT.md §4.5`
- مقارنة: `js/app.js:p7Score()`

### التصميم البصري و CSS

#### الأزرار والألوان والأنيميشن — 🟢 مكتمل

أزرار كبيرة مناسبة للبروجكتور. ألوان الحروف من `:root`. انتقال هادئ `p6-question-enter`. حالة تشغيل صوت مرئية. وضعا ليل/نهار يعملان.

#### دعم اللغة الصينية — 🔴 مفقود

P6 بالكامل باللغة العربية. لا تعليمات صينية مساعدة رغم أن الفئة المستهدفة طلاب صينيون A0 (من Doc 02). مراحل أخرى مثل P3 تحتوي `chinesePinyin` لكنها لا تظهر في P6.

- `P6_AUDIT_REPORT.md §3.6(4)`

## الخلاصة

**التنفيذ الحالي لـ P6 سليم معمارياً وبصرياً ضمن نطاقه.**

كل ما هو منفَّذ (D1/D2/D3) يعمل بشكل صحيح، يتبع قواعد المعمارية، ويستخدم الأنماط الموحدة. الفجوات الموجودة ليست أخطاء تنفيذ بل **أنشطة لم تُبنَ بعد** بانتظار قرارات تربوية (QD-04).
