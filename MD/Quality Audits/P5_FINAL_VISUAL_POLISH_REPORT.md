## 2. التحسينات البصرية

### 2.1 زيادة ارتفاع البطاقة (~12%)

| الخاصية | قبل | بعد |
|---------|-----|-----|
| padding عمودي | `clamp(1.2rem, 3vh, 2.5rem)` | `clamp(1.6rem, 3.8vh, 3rem)` |
| padding أفقي | `clamp(1.5rem, 4vw, 3rem)` | `clamp(1.8rem, 4.5vw, 3.2rem)` |
| gap بين العناصر | `clamp(0.6rem, 1.8vh, 1.2rem)` | `clamp(0.9rem, 2.4vh, 1.6rem)` |

### 2.2 تحسين المسافات الداخلية

| العنصر | التغيير |
|--------|---------|
| `.p5-block` gap | من `clamp(0.3rem, 1vh, 0.6rem)` إلى `clamp(0.4rem, 1.2vh, 0.8rem)` |
| `.p5-word-display` padding | من `0.15em 0` إلى `0.25em 0` |
| `.p5-meaning-caption` | إضافة `margin-top: 0.15em` لفصل أفضل عن الكلمة |

### 2.3 تحسين بطاقة الهوية

| العنصر | قبل | بعد |
|--------|-----|-----|
| padding عمودي | `clamp(0.45rem, 1.1vh, 0.8rem)` | `clamp(0.6rem, 1.5vh, 1rem)` |
| padding أفقي | `clamp(1.2rem, 3vw, 2.2rem)` | `clamp(1.5rem, 3.5vw, 2.8rem)` |
| الحرف (font-size) | `clamp(2.2rem, 5.5vh, 3.8rem)` | `clamp(2.4rem, 6vh, 4rem)` |
| الحرف (text-shadow) | — | `0 1px 8px color-mix(...)` — توهّج خفيف |
| الفاصل (width) | `2px` | `1.5px` — أرفع وأنعم |
| الفاصل (margin) | `clamp(0.5rem, 1.2vw, 1rem)` | `clamp(0.7rem, 1.6vw, 1.3rem)` — مسافة أوسع |
| الاسم والصوت (font-size) | `clamp(1rem, 2.5vh, 1.5rem)` | `clamp(0.95rem, 2.3vh, 1.35rem)` — أصغر قليلاً |
| الاسم والصوت (font-weight) | `700` | `600` — أخف ليبرز الحرف أكثر |
| الاسم (color) | `70%` من لون الحرف | `60%` — أقل تشبعاً |
| border | `30%` opacity | `25%` — أنعم |

### 2.4 Premium depth

| العنصر | التغيير |
|--------|---------|
| `.p5-card` box-shadow | إضافة `inset 0 1px 0 rgba(255,255,255,0.04)` — highlight خفيف على الحافة العلوية |
| `.p5-card` shadow radius | من `32px` إلى `40px` — ظل أوسع وأنعم |
| `.p5-identity-card` shadow | إضافة `0 1px 4px rgba(0,0,0,0.08)` طبقة ثانية |
