## البُعد 1: الهدف التربوي — هل P5 تحقق غرضها؟

### الهدف المُعلَن
> ربط الحرف المعزول بموضعه داخل كلمات حقيقية بسيطة (lesson-01.js, سطر 407)

### ما تقوله الوثائق المرجعية

| الوثيقة | ما يُطلب من P5 |
|---------|----------------|
| Doc 03 (الخطة التربوية) | الدقيقة 55-75: كتابة الكلمات (بَاب/بَيْت/نَار/ثَوْب) + نطقها مع الإشارة لصورتها. الدقيقة 75-100: الجملة الأولى ("هَذَا بَاب") + ترديد + عمل ثنائي |
| Doc 04 (التنفيذ) | 7 أنشطة (5.1–5.7): تقديم كلمات بالصورة والصوت ← قراءة صفية ← مؤشر عشوائي ← تقديم جملة ← ترديد ← عمل ثنائي ← عكس إدراكي |
| Doc 07 (خريطة التنفيذ) | P5a (55-75د): بطاقة كلمة بـ "صورة + كلمة بتشكيل كامل + ترجمة صينية + أيقونة صوت" ← عرض رباعي ← مؤشر عشوائي. P5b (75-100د): شريط الجملة + مؤقت العمل الثنائي |
| DESIGN_PHILOSOPHY.md | الكشف التدريجي: الكلمة → تمييز → صوت → معنى |

### التقييم

| المعيار | الحالة | ملاحظة |
|---------|--------|--------|
| ربط حرف → كلمة | ✅ متحقق | الحرف المستهدف يُبرز بلونه داخل الكلمة + highlight box |
| كشف تدريجي | ✅ متحقق | 4 خطوات: كلمة → تمييز الحرف → صوت → معنى |
| التشكيل الكامل | ✅ متحقق | `word.word` يحتوي التشكيل ("بَاب"، "بَيْت") |
| صوت الكلمة | ✅ متحقق | زر ▶ + ملف صوت + choral button |
| الترديد الجماعي | ✅ متحقق | زر "👥 ردّد" مع choral-flash |
| صورة الكلمة | ❌ غائب | Doc 07 يطلب "صورة" — لا صورة في التنفيذ |
| ترجمة صينية | ❌ غائب | Doc 07 يطلب "ترجمة صينية" — المعنى الحالي بالإنجليزية فقط: `"باب (door)"` |
| عرض رباعي للكلمات | ❌ غائب | Doc 07 يطلب "بعد الأربع: عرض رباعي" — لا Quad View في P5 |
| مؤشر الكلمة العشوائي | ❌ غائب | Doc 07 (ن-14) يطلب "مؤشر الكلمة العشوائي" — غير منفذ |
| الجملة الأولى (P5b) | ❌ غائب | Doc 03+04+07 جميعها تطلب "هَذَا بَاب" — لا وجود لمكون الجملة |
| تقييم تكويني | ❌ غائب | لا تحقق من فهم الطالب داخل P5 |

### الخلاصة
**P5 تحقق الجزء الأساسي من هدفها** (ربط الحرف بالكلمة) لكنها تمثل فقط **P5a من Doc 07** — المفردات فقط. الجملة (P5b)، الصورة، الترجمة الصينية، العرض الرباعي للكلمات، والمؤشر العشوائي — كلها مذكورة في الوثائق لكنها غير منفذة.

**ملاحظة مهمة**: غياب P5b (الجملة) قد يكون قراراً واعياً — تقسيم المحاضرة لـ 7 مراحل (P1-P7) بدل البنية الأصلية (P5a+P5b، P6a+P6b). هذا القرار مشروع لأنه يبسّط بنية التطبيق، لكن يعني أن محتوى "الجملة" غائب تماماً من التطبيق الحالي.

## البُعد 2: تسلسل الكشف التدريجي — هل الترتيب أمثل؟

### التسلسل الحالي

```
الخطوة 0: الكلمة كاملة (word)    ← الكلمة بحروفها مع underline على الحرف المستهدف
الخطوة 1: تمييز الحرف (target)   ← highlight box: الحرف + اسمه + فونيمه
الخطوة 2: الصوت (audio)          ← زر تشغيل + صوت تلقائي + زر ترديد
الخطوة 3: المعنى (meaning)       ← emoji 🔤 + المعنى بالإنجليزية
```

### تسلسل Doc 07 (P5a)

```
1) بطاقة كلمة واحدة في المركز: صورة + كلمة بتشكيل كامل + ترجمة صينية + أيقونة صوت
2) بعد الأربع: عرض رباعي
3) المعلم يضغط Space لكشف كل كلمة
```

### التحليل

| الجانب | التنفيذ الحالي | Doc 07 | التقييم |
|--------|---------------|--------|---------|
| تسلسل المعلومات | كلمة → حرف → صوت → معنى (4 خطوات) | كلمة + صورة + صوت + ترجمة (مجتمعة في بطاقة) | ⚠️ Doc 07 لا يفصّل خطوات الكشف بنفس الطريقة |
| الصوت التلقائي | عند الخطوة 2 فقط | عند كشف الكلمة | ⚠️ التنفيذ يؤخر الصوت |
| الحرف المستهدف كخطوة مستقلة | نعم (الخطوة 1) | غير مذكور صراحةً | ✅ إضافة ذكية — تربط P5 بـ P3 |
| المعنى آخراً | نعم (الخطوة 3) | لا ترتيب محدد | ✅ مبرر تربوياً — الصوت قبل المعنى |

### الرأي التربوي

التسلسل الحالي **سليم تربوياً ومتسق مع فلسفة المشروع**:

1. **الكلمة أولاً (الخطوة 0)** — الطالب يرى الشكل المكتوب كاملاً قبل أي تفسير. هذا يعطي لحظة اكتشاف: "أنا أعرف هذا الحرف!"
2. **تمييز الحرف (الخطوة 1)** — قرار ممتاز غير موجود في Doc 07 لكنه يربط P5 بـ P3 مباشرة. يقول للطالب: "الحرف الذي تعلمته يظهر هنا."
3. **الصوت (الخطوة 2)** — الطالب يسمع نطق الكلمة كاملة بعد أن رآها. التشغيل التلقائي عند هذه الخطوة مناسب.
4. **المعنى آخراً (الخطوة 3)** — يمنع الطالب من "القراءة بالترجمة". يُجبره على معالجة الشكل والصوت أولاً.

**الملاحظة**: تأخير الصوت إلى الخطوة 2 (بعد خطوتين) يعني أن المعلم يضغط Space مرتين قبل أن يسمع الطلاب أي شيء. في فصل حقيقي، قد يرغب المعلم في تشغيل الصوت فوراً مع الخطوة 0 — لكن التنفيذ الحالي يمنحه زر الصوت في البطاقة السابقة (history strip) إذا أراد المقارنة.

## البُعد 3: التصميم البصري — هل يخدم الفصل الدراسي؟

### التخطيط الأفقي (Grid)

```css
grid-template-columns: minmax(230px, 1.3fr) minmax(180px, 1fr) minmax(190px, 1fr) minmax(180px, 1fr);
grid-template-areas: "word target audio meaning";
```

| العنصر | المعيار | الحالة | ملاحظة |
|--------|---------|--------|--------|
| تخطيط الكارت | أفقي No-scroll | ✅ | Grid 4 أعمدة RTL — مصمم للشاشة الواحدة |
| حجم الكلمة | بروجكتور | ✅ | `clamp(2.6rem, 13vh, 5.5rem)` — كبير وواضح |
| RTL | كامل | ✅ | `direction: rtl` على word-display + grid-areas RTL |
| الحرف المستهدف | underline | ✅ | `::after` pseudo-element بلون الحرف |
| highlight box | مرئي | ⚠️ | `var(--fs-xl)` للحرف لكن `var(--fs-sm)` للاسم — فارق كبير |
| زر الصوت | واضح | ✅ | border ملون + ▶ + الكلمة بالتشكيل |
| المعنى | مقروء | ⚠️ | `var(--fs-sm)` + emoji 🔤 — صغير جداً للبروجكتور |
| فاصل الأعمدة | موجود | ✅ | `border-inline-end` بين كل عمود |
| max-height | محكوم | ✅ | `min(80vh, 620px)` — لا overflow |
| Progress dots | مرئية | ⚠️ | 12px + opacity 0.3 — صغيرة وخافتة |

### المساحة البيضاء — السؤال المحوري

**المشكلة الظاهرة**: عند الخطوة 0 (كشف الكلمة فقط)، تظهر الكلمة ("بَاب") في المنطقة اليمنى من البطاقة بينما 75% من مساحة البطاقة فارغة تماماً (الأعمدة الثلاثة الأخرى مخفية).

**التحليل**:

| المنظور | الحكم | التبرير |
|---------|-------|---------|
| تربوياً | ✅ المساحة البيضاء **مقصودة** | الكشف التدريجي يتطلب إخفاء المحتوى. الفراغ يركّز الانتباه على الكلمة فقط — مبدأ "الانتباه مورد محدود" |
| بصرياً | ⚠️ ضعف تصميمي | الكلمة (3 حروف) في ركن بطاقة عرضها 1300px تبدو "ضائعة". عين المشاهد تبحث عن محتوى إضافي |
| من منظور البروجكتور | ⚠️ مساحة مُهدرة | شاشة الفصل مورد ثمين — 75% فارغ يعني الحرف أصغر مما يمكن أن يكون |
| من منظور المعلم | ✅ مقبول | المعلم يعرف أن المحتوى سيظهر — الـ hint يقول "اضغط Space لكشف: تمييز الحرف" |

**الخلاصة**: المساحة البيضاء ليست خطأً — هي نتيجة طبيعية لتخطيط Grid أفقي مع كشف تدريجي. لكنها **فرصة ضائعة** لاستغلال المساحة في الخطوات المبكرة.

### نقاط القوة البصرية
- **التخطيط الأفقي Grid** — قرار ممتاز يحل مشكلة الـ scroll العمودي. CSS comment في سطر 2179 يوثق السبب.
- **underline على الحرف المستهدف** (`::after`) — إشارة بصرية ذكية تلفت النظر بدون تشتيت
- **History Strip** — ذاكرة بصرية مصغرة تبني إحساس التقدم. opacity 0.55 تمنعها من منافسة البطاقة الحالية.
- **ترميز لوني متسق** — لون الحرف ينتقل من P3 إلى P5: الحرف، الـ underline، الـ highlight box، زر الصوت — كلها بنفس اللون.
- **الفواصل العمودية** (`border-inline-end`) بين الأعمدة — تعزز الهيكلية.

### نقاط الضعف البصرية
1. **المعنى صغير جداً** — `var(--fs-sm)` مع emoji 🔤 في آخر عمود (الأبعد عن العين RTL). من بُعد 5 أمتار على البروجكتور، قد لا يُقرأ.
2. **Progress dots خافتة** — 12px بـ opacity 0.3 للـ inactive. على بروجكتور قد تكون غير مرئية.
3. **لا صورة** — Doc 07 يطلب صورة لكل كلمة. غيابها يحرم الطالب من الرابط البصري-المعنوي الأقوى.
4. **المعنى بالإنجليزية لا بالصينية** — "باب (door)" بدل "باب (门 mén)". الطالب صيني — الإنجليزية لغة ثالثة قد لا يتقنها.
5. **الخطوة 0 تبدو "فارغة"** — الكلمة وحيدة في بطاقة كبيرة.

## البُعد 4: تحليل من 5 منظورات

### المنظور 1: المعلم داخل الفصل

| السؤال | الإجابة |
|--------|---------|
| هل يعرف ماذا يفعل في كل خطوة؟ | ✅ نعم — الـ hint يُحدَّث في كل خطوة: "اضغط Space لكشف: تمييز الحرف / الصوت / المعنى" |
| هل يستطيع التراجع؟ | ✅ نعم — ← يتراجع خطوة بخطوة، ثم كلمة بكلمة |
| هل يستطيع العودة لكلمة سابقة؟ | ✅ نعم — History Strip قابل للنقر + زر "→ السابق" + Review Panel مع Pin |
| هل يستطيع تشغيل الصوت يدوياً؟ | ✅ نعم — زر ▶ في البطاقة متاح دائماً بعد الكشف |
| هل يعرف متى ينتهي؟ | ✅ نعم — progress dots + "الكلمة X من 5" + زر "التمييز السمعي ←" في آخر كلمة |
| هل هناك ما يُربكه؟ | ⚠️ نعم — عند الخطوة 0، المعلم يرى كلمة واحدة في بطاقة كبيرة فارغة. قد يظن أن هناك خطأ. كما أن زر "التالي ←" و`Space` يفعلان نفس الشيء — لكن Space يكشف خطوة بينما الزر يقفز للكلمة التالية |

**المشكلة الرئيسية للمعلم**: لا توجد تعليمة توضّح **ما يقوله** في كل خطوة. P3 لديها نفس المشكلة لكن في P5 أكثر حدة لأن الكلمات تحتاج سياقاً: هل يقرأ الكلمة أولاً؟ هل يسأل الطلاب "أين الحرف"؟ هل ينطق ثم يكشف أم يكشف ثم ينطق؟ الـ hint يقول "ماذا تضغط" لا "ماذا تقول".

### المنظور 2: الطلاب المبتدئين (A0 صينيون)

| السؤال | الإجابة |
|--------|---------|
| هل يستطيعون قراءة الكلمة؟ | ⚠️ جزئياً — رأوا الحروف في P3 لكن لم يتمرنوا على القراءة التركيبية (ب + ا = با). الكلمة قد تكون "رسم" لا "نص" بالنسبة لهم |
| هل يتعرفون على الحرف المستهدف؟ | ✅ نعم — اللون + underline + highlight box كلها تشير للحرف |
| هل يفهمون المعنى؟ | ⚠️ مشكوك — "باب (door)" — إذا كان مستوى الإنجليزية ضعيفاً، لن يفهم المعنى. لا صورة تساعده. لا ترجمة صينية |
| هل يحصلون على قيمة من كل خطوة كشف؟ | ⚠️ متفاوت — الخطوة 0 (الكلمة) قيمتها عالية. الخطوة 1 (تمييز الحرف) تعزيزية. الخطوة 2 (الصوت) عالية. الخطوة 3 (المعنى) ضعيفة بدون صورة/ترجمة صينية |
| هل هناك فرصة للمشاركة؟ | ⚠️ محدودة — الترديد (choral) موجود. لكن لا يوجد نشاط "أين الحرف؟" أو "ما هذه الكلمة؟" — الطالب مستقبِل |

### المنظور 3: العرض على البروجكتور

| العنصر | الحالة من 5+ أمتار |
|--------|-------------------|
| الكلمة ("بَاب") | ✅ واضحة — `clamp(2.6rem, 13vh, 5.5rem)` |
| الحرف المستهدف underline | ✅ واضح — 4px بلون مميز |
| highlight box | ✅ حرف واضح (`--fs-xl`) — لكن الاسم والفونيم (`--fs-sm`) قد يختفيان |
| زر الصوت | ✅ واضح — حجم مناسب |
| المعنى | ❌ غير مقروء — `--fs-sm` + emoji صغير. من 5 أمتار لا يُرى |
| History Strip | ⚠️ ثانوي بالتصميم — opacity 0.55، مقبول لأنه ليس العنصر الرئيسي |
| Progress dots | ⚠️ بالكاد مرئية |
| تعليمة "الكلمة X من 5" | ⚠️ `--fs-sm` — صغيرة |

### المنظور 4: التسلسل التعليمي (P3 → P5 → P6)

| الانتقال | التقييم |
|---------|---------|
| P3 → P5 | ⚠️ فجوة — P3 تنتهي بالتقييم السريع (assess). P4 تغطي الكتابة. P5 تقفز مباشرة لكلمات كاملة. لا يوجد نشاط انتقالي يربط "الحرف المفرد" بـ"الحرف داخل كلمة" |
| P5 داخلياً | ✅ جيد — التقدم من كلمة بسيطة (بَاب — 3 حروف، حرفان مستهدفان) إلى كلمات أعقد (ثَوْب — حرف واحد مستهدف بين حروف جديدة) |
| P5 → P6 | ⚠️ مفاجئ — P5 ينتهي بزر "التمييز السمعي ←" بدون مراجعة تجميعية. لا Quad View للكلمات. الطالب انتقل من "رؤية كلمات" إلى "تمييز أصوات" بدون تلخيص |

### المنظور 5: الحمل المعرفي (Cognitive Load)

| المعيار | التقييم |
|---------|---------|
| عنصر واحد في كل خطوة | ✅ — كل Space يكشف عموداً واحداً |
| لا يتعايش مفهومان جديدان | ✅ — الكلمة ثم الحرف ثم الصوت ثم المعنى |
| كمية المعلومات لكل كلمة | ✅ مناسبة — 4 عناصر (كلمة، حرف، صوت، معنى) |
| 5 كلمات في المرحلة | ⚠️ كثير قليلاً — 5 كلمات × 4 خطوات = 20 ضغطة. لكن الكلمات بسيطة (3 حروف) والوتيرة بيد المعلم |
| تراكم المعلومات | ✅ History Strip يبني ذاكرة بصرية تراكمية |

## البُعد 5: مقارنة مع تصميم P3 بعد التحسينات

### ما يملكه P3 ولا يملكه P5

| الميزة | P3 | P5 |
|--------|----|----|
| اسم الحرف في البطاقة | ✅ card-char-name | ✅ p5-target-label (داخل highlight box) |
| تعليمة واضحة للبروجكتور | ✅ محسّنة (`--fs-sm`, `weight 500`) | ⚠️ `--fs-sm` + `--text-secondary` فقط |
| Quad View تجميعي | ✅ يعرض الحروف الأربعة | ❌ لا Quad View للكلمات |
| Micro-Assessment | ✅ تقييم سريع بالأصابع | ❌ لا تقييم |
| Retreat كامل | ✅ assess → quad → single | ✅ step → step → word → word |
| ترميز لوني | ✅ لون لكل حرف | ✅ نفس الألوان — متسق |

### ما يملكه P5 ولا يملكه P3

| الميزة | P5 | P3 |
|--------|----|----|
| History Strip | ✅ ذاكرة بصرية للكلمات السابقة | ❌ لا تاريخ (completedLetters فقط في dots) |
| Teacher Review Panel | ✅ مراجعة + تثبيت + إغلاق | ❌ لا panel مراجعة |
| Choral Repeat Button | ✅ مع flash animation | ✅ موجود أيضاً |
| Navigation Buttons | ✅ → السابق / التالي ← | ❌ Space فقط |

## البُعد 6: نقاط القوة والضعف

### نقاط القوة — يجب عدم تغييرها

1. **التخطيط الأفقي Grid** — محسّن للبروجكتور، يمنع الـ scroll، يعرض كل المعلومات أفقياً
2. **تسلسل الكشف التدريجي** (كلمة → حرف → صوت → معنى) — منطقي وسليم تربوياً
3. **History Strip** — ابتكار ممتاز يبني إحساس التقدم والتراكم
4. **Teacher Review Panel + Pin** — أداة مفيدة للمعلم لمراجعة كلمة سابقة أثناء التدريس
5. **الترميز اللوني المتسق** — نفس ألوان P3 تنتقل لـ P5
6. **Choral Flash** — تأثير بصري واضح عند الترديد
7. **Retreat handler** — يعمل بشكل كامل ومنطقي (خطوة ← خطوة ← كلمة ← كلمة)
8. **عمود "الحرف المستهدف"** كخطوة مستقلة — إضافة ذكية تربط P5 بـ P3

### نقاط الضعف

| # | المشكلة | الأثر التربوي | الأثر البصري | المرجع |
|---|---------|--------------|-------------|--------|
| 1 | **غياب الصورة** | عالي — الطالب المبتدئ يحتاج رابطاً بصرياً | عالي — مساحة فارغة يمكن استغلالها | Doc 07: "صورة" |
| 2 | **المعنى بالإنجليزية لا بالصينية** | عالي — الطالب الصيني قد لا يفهم "door" | لا يؤثر | Doc 07: "ترجمة صينية" |
| 3 | **غياب Quad View للكلمات** | متوسط — لا ملخص تجميعي | متوسط | Doc 07: "عرض رباعي" |
| 4 | **المعنى صغير جداً للبروجكتور** | منخفض (المعلم يشرح شفوياً) | عالي — غير مقروء من بُعد | Projector-first |
| 5 | **غياب التقييم التكويني** | عالي — لا تحقق من فهم الطالب | لا يؤثر | DESIGN_PHILOSOPHY §5 |
| 6 | **لا تعليمة "ماذا يقول المعلم"** | متوسط — المعلم يعرف "ماذا يضغط" لا "ماذا يقول" | لا يؤثر | Doc 04 §5.1-5.7 |
| 7 | **المساحة البيضاء في الخطوة 0** | منخفض | متوسط — تبدو فارغة | — |
| 8 | **غياب المؤشر العشوائي** | متوسط — لا تحدي للطالب | لا يؤثر | Doc 07 (ن-14) |

### المشاكل المحتملة داخل الفصل الحقيقي

1. **الطالب لا يفهم المعنى**: يرى "باب (door)" — إذا كانت إنجليزيته ضعيفة لن يفهم. ينتظر شرح المعلم الشفوي. هذا يعني أن الخطوة 3 (المعنى) لا تؤدي وظيفتها المستقلة.

2. **الطالب لا يستطيع "قراءة" الكلمة**: P3 علّمته الحروف المفردة. لكن "بَاب" = ب + ا + ب — الألف حرف جديد لم يُدرَّس. الطالب يرى شكلاً لا يستطيع فكّه. **هذه ليست مشكلة في P5 بل في تصميم المنهج** — الألف ستُدرَّس في المحاضرة الثانية. لكن يعني أن P5 في المحاضرة الأولى هي "تعرّف بصري" أكثر من "قراءة".

3. **5 كلمات × 4 خطوات = 20 ضغطة Space**: قد يشعر المعلم بالرتابة. لا تنوع في النشاط — نفس النمط يتكرر 5 مرات. Doc 04 يقترح أنشطة متنوعة (قراءة صفية، مؤشر عشوائي) لكسر الرتابة.

4. **الانتقال من P5 لـ P6 مفاجئ**: الطالب كان يرى كلمات ومعانٍ، فجأة ينتقل لتمييز أصوات حروف مفردة. لا مراجعة تجميعية تلخّص ما تعلّمه.

## البُعد 7: مقارنة مع أنظمة تعليم المفردات

| النظام | النهج | ما يملكه P5 | ما يفتقده P5 |
|--------|------|------------|-------------|
| **TPR (Total Physical Response)** | الجسم يستجيب للكلمة | الترديد الجماعي | حركة جسدية مرتبطة بالكلمة |
| **Flashcard Systems** (Anki/Quizlet) | بطاقة: صورة + كلمة + صوت | كلمة + صوت | الصورة |
| **Communicative Approach** | الكلمة في سياق حقيقي | المعنى مذكور | السياق الحقيقي (Doc 03: "أشر لباب الفصل") |
| **Picture-Word Inductive Model** | صورة → كلمات → جمل | — | الصورة كنقطة انطلاق |
| **Realia-Based Teaching** | أشياء حقيقية في الفصل | — | الإشارة لأشياء حقيقية (Doc 03: "أشر لباب الفصل وقل: هَذَا بَاب") |

### الخلاصة
P5 تستخدم نهج **Flashcard** (بطاقة بكشف تدريجي) وهو مناسب لعرض الشاشة. لكن الوثائق الأصلية تطلب نهجاً أقرب لـ **Realia-Based** (الإشارة لأشياء حقيقية في الفصل). هذا الفارق طبيعي لأن التطبيق أداة عرض لا بديل عن المعلم — المعلم هو من يشير ويربط بالواقع.

## البُعد 8: الرأي المهني — التصور المثالي لـ P5

### السؤال: هل نحافظ على الكشف التدريجي الحالي؟

**نعم — التسلسل الحالي (كلمة → حرف → صوت → معنى) سليم ويجب الحفاظ عليه.** لكن يحتاج تعزيزاً في 3 محاور:

### المحور 1: تعزيز المحتوى (بدون تغيير التسلسل)

**أ) إضافة الصورة** — العنصر الأكثر تأثيراً الغائب. صورة بسيطة (باب، بيت، تمر، ثوب، نار) تضاف في عمود المعنى أو كعنصر مستقل. الطالب المبتدئ يربط الشكل المكتوب بصورة ذهنية أقوى من ترجمة نصية.

> **ملاحظة تنفيذية**: هذا يتطلب إضافة حقل `image` في بيانات `lesson-01.js` أو استخدام emoji كبديل مؤقت (🚪 للباب، 🏠 للبيت، 🌴 للتمر، 👘 للثوب، 🔥 للنار). **القيد**: `lesson-01.js` مجمّد — أي حل يجب أن يعمل بالبيانات الموجودة أو يُضاف في ملف منفصل.

**ب) تحسين المعنى** — إذا لم تُضف صورة، على الأقل:
- تكبير حجم المعنى (`--fs-md` بدل `--fs-sm`)
- إضافة ترجمة صينية بجانب الإنجليزية (البيانات تحتوي `chinesePinyin` للحروف — يُحتاج مقابل للكلمات)

**ج) إضافة اسم الحرف بشكل أوضح** — الـ highlight box يعرض "ب باء — /ب/" لكن بحجم `--fs-sm`. اسم الحرف يحتاج بروزاً أكبر.

### المحور 2: تحسين التجربة البصرية

**أ) استغلال المساحة في الخطوة 0** — عند كشف الكلمة فقط، يمكن أن تتوسع الكلمة لتملأ البطاقة (وتعود لعمودها عند كشف الخطوة التالية). هذا يعالج مشكلة "الفراغ" ويجعل الكلمة أكبر وأوضح.

> **بديل أبسط**: عرض الكلمة في تخطيط مركزي (centered) عند الخطوة 0، ثم الانتقال للـ Grid عند الخطوة 1. لكن هذا قد يسبب "قفزة بصرية" مزعجة.

**ب) تكبير عمود المعنى** — `--fs-md` بدل `--fs-sm`. إضافة emoji أكبر أو صورة مصغرة.

**ج) تحسين Progress dots** — 16px بدل 12px، أو استبدالها بشريط تقدم يحمل اسم الكلمة.

### المحور 3: إضافة نشاط تفاعلي

**أ) Quad View للكلمات** — بعد الكلمة الخامسة، عرض الكلمات الخمس في شبكة واحدة (مثل P3 Quad View). هذا يوفر:
- مراجعة تجميعية قبل P6
- فرصة للمعلم للإشارة والمقارنة
- انتقال أقل مفاجئ لـ P6

**ب) Micro-Assessment** — مشابه لما أُضيف في P3:
- تشغيل صوت كلمة عشوائية
- الطلاب يرفعون أصابعهم (1-5) للكلمة الصحيحة
- المعلم يكشف الإجابة بـ Space
- قابل للتخطي

**ج) نشاط "أين الحرف؟"** — المعلم يعرض كلمة ويسأل: "أين الباء؟" قبل كشف الخطوة 1 (تمييز الحرف). هذا يحول الطالب من مستقبِل إلى مشارك.

### ما لا يحتاج تغييراً

- **التخطيط الأفقي Grid** — ممتاز ومُحسَّن
- **تسلسل الكشف** (word → target → audio → meaning) — سليم تربوياً
- **History Strip** — ابتكار ناجح
- **Teacher Review Panel + Pin** — أداة قيّمة
- **الترميز اللوني** — متسق ومهم
- **Choral Flash** — فعّال
- **Retreat handler** — كامل ومنطقي
- **`advanceP5()` auto-play عند الخطوة 2** — مناسب

### الشكل المثالي لـ P5 داخل الفصل

│  التدفق المثالي                                              │

│  [كلمة 1] → 4 خطوات كشف → (المعلم يشير لباب الفصل)         │
│  [كلمة 2] → 4 خطوات كشف → (المعلم يُري صورة بيت)           │
