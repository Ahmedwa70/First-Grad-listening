# P4 — تأجيل بطاقات رسم الحروف

> **الحالة: 🟡 مؤجَّل مؤقتاً** — لحين اكتمال إعداد مسارات رسم الحروف.
> القرار المرجعي: `md/Governance/PROJECT_DECISIONS.md#QD-18` · التاريخ: 2026-08-23

## لماذا

لم يكتمل بعد إعداد مسارات رسم جميع الحروف في Arabic Stroke Engine. عرض بطاقات الرسم على الطلاب ضمن التسلسل الطبيعي للدرس يعني تقديم محتوى غير مكتمل أمام الصف، لذلك أُخفيت من مسار العرض مع إبقاء الوصول إليها متاحاً للمعاينة أثناء التطوير.

**التأجيل يخص العرض فقط.** لم تُحذف أي بيانات ولم يُحذف أي كود: `LESSON_01.strokeGuides` و`renderP4()` و`renderP4Card()` و`p4StartAnimation()` وكل أنماط CSS باقية كما هي وتعمل.

## السلوك الحالي

| مسار الدخول إلى P4 | ما يظهر |
|---|---|
| **تسلسلي** — تقدّم من آخر صفحة في P3 (`advance` أو زر تخطي التقييم) | شاشة المقارنة مباشرةً: `مقارنة الكتابة — الحروف الأربعة`. بطاقات الرسم مخفية، وزر `عودة للبطاقات` مخفي حتى لا يقود إلى الجزء المؤجَّل. |
| **مباشر** — زر P4 في الشريط العلوي أو مفتاح `4` | P4 كامل من بدايته: بطاقة الحرف الأول، حركة الرسم، والخطوات الأربع. لا شيء مخفي. |

في الحالتين يبقى `Space` / `تقدم` من شاشة المقارنة منتقلاً إلى P5 كالمعتاد.

## آلية التنفيذ — `js/app.js`

```js
// المفتاح الوحيد الذي يحكم التأجيل
const P4_WRITING_PRACTICE_DEFERRED = true;

function p4WritingPracticeHidden() {
  return P4_WRITING_PRACTICE_DEFERRED && STATE.p4EntryMode === 'sequential';
}
```

- **`goToPhase(index, options = {})`** تسجّل `STATE.p4EntryMode`:
  `options.sequential === true` ← `'sequential'`، وإلا `'direct'`.
  الافتراضي `'direct'`، لذلك كل نداء قائم لـ `goToPhase` يبقى على السلوك الكامل بلا تعديل.
- **مخرجا P3 وحدهما** يمرّران `{ sequential: true }`: نهاية التقييم، و`p3SkipAssess()`.
- **`initP4()`** تفرّعت: في وضع التأجيل التسلسلي تستدعي `renderP4Compare()` مباشرةً وتتخطى `renderP4()`.
- **`renderP4Compare()`** تحذف زر `عودة للبطاقات` عندما `p4WritingPracticeHidden()`.
- **`renderP4Card()`** تعود مبكراً في وضع المقارنة، فلا يستبدل الكشف/الإخفاء الطارئ تلميح المقارنة بتلميح خطوة غير معروضة.

## كيف يُرفع التأجيل

اجعل القيمة `false`:

```js
const P4_WRITING_PRACTICE_DEFERRED = false;
```

يعود P4 كاملاً في المسارين معاً، ويعود زر `عودة للبطاقات` تلقائياً. **لا يلزم أي تغيير آخر** — لا في `goToPhase` ولا في مخرجَي P3 ولا في الحارس داخل `renderP4Card()`؛ جميعها تبقى صحيحة بعد رفع التأجيل.

### شرط الرفع

1. اكتمال مسارات رسم الحروف الأربعة (ب ت ث ن) في Arabic Stroke Engine واعتمادها بصرياً.
2. 🔴 **استبدال الرسم اليدوي داخل `renderP4()`** بمخرجات Arabic Stroke Engine.

> **تحذير مُلزِم (QD-19):** `renderP4()` ما زالت ترسم الحرف بمسار SVG مؤلَّف يدوياً (`guide.svgPath` + `guide.dotPositions`) — وهو النمط المرفوض نفسه الذي حُذف من شاشة المقارنة في 2026-08-23. رفع التأجيل مع بقاء هذا المسار **مخالفة مباشرة لـ QD-19**. لا يُرفع التأجيل قبل استبدال الرسم.
>
> القاعدة: شكل الحرف من محرف الخط الحقيقي أو من Arabic Stroke Engine حصراً. الأسهم ونقاط البداية ومؤشرات الاتجاه مستثناة — راجع `md/Governance/DESIGN_PHILOSOPHY.md`.
