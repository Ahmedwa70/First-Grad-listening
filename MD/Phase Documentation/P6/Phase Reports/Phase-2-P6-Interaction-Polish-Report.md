## 1. الملخص

حوّل Phase 2 تجربة P6 من **لوحة بصرية ثابتة** إلى **تدريب سمعي تدريجي يقوده المدرّس** عبر ثلاثة تحسينات تفاعلية فقط:

1. **حالة تشغيل الصوت:** ضغط أي زر صوت يُضيئه مع رسالة "🔊 جاري الاستماع..." عبر class مُدار من JS دون DOM جديد ودون تغيير AudioManager.
2. **كشف تدريجي لـ D1 (عدّ الأصابع):** ثلاث خطوات يتحكم بها المدرّس بالكامل (Space أو زر): **الحرف ← اسم الحرف ← عدد الأصابع والنقاط** — بدل انفجار المعلومات دفعة واحدة.
3. **لوحة تعليم الإجابة:** منطقة الإجابة أصبحت لوحة تعليم ("✓ الإجابة الصحيحة" + الحرف + الاسم الصوتي + عدد الأصابع + النقاط الذهبية وموضعها) بألوان الهوية navy/teal/gold.

لم تُغيّر أي ID/class يعتمد عليها المشروع، ولم يُمَس Layout الذي أثبتته Phase 1، ولم تُضف مكونات أو مؤقتات أو نشاطات جديدة.

## 4. التغييرات (Before → After + السبب)

### 4.1 Task 1 — حالة تشغيل الصوت

**JS (`app.js`):**
- **Before:** أزرار P6 تستدعي `p3PlaySound('...')` مباشرة؛ لا تغذية راجعة عند التشغيل.
- **After:**
  - `let p6SoundTimer = null;`
  - `function p6MarkSoundButton(el)` — يضيف class `.is-playing` على الزر المضغوط وعلى منطقته (`.p6-play-zone`/`.p6-pair-zone`/`.p6-close-zone`)، ويُزيله بعد 2600ms.
  - `function p6PlaySound(letterId, el)` — `p3PlaySound(letterId)` ثم `p6MarkSoundButton(el)`. (أُضيف كـ wrapper؛ `p3PlaySound` و`AudioManager` كما هما.)
  - أزرار D1/D2/D3 في `renderP6` أصبحت `onclick="p6PlaySound('...', this)"`.

**CSS (`style.css`):**
- **Before:** لا حالة تشغيل مرئية على أزرار P6.
- **After:**
  - `.p6-big-play.is-playing` / `.p6-pair-play.is-playing` / `.p6-close-btn.is-playing` → توهج teal (`box-shadow 0 0 30px`) + `scale(1.05)` + تعبئة teal أوضح.
  - `.p6-play-zone.is-playing::after` وغيرها → `content: '🔊 جاري الاستماع...'` مع نبض `p6ListenPulse` (بدون DOM جديد).
- **السبب:** المعلم والطلاب يعرفون أن الصوت يعمل فعلاً. الاعتماد على class مُدار خارجياً (بدل `onended` غير الموثوق في Web Speech) هو الحل الموثوق دون تغيير AudioManager.

### 4.2 Task 2 — الكشف التدريجي لـ D1

**JS (`app.js`):**
- **Before:** `advanceP6` يفتح الإجابة كاملة دفعة واحدة (حرف + أصابع + اسم)، والضغطة التالية تنتقل.
- **After:**
  - `STATE.p6RevealStep: 0` (حقل جديد فقط — بنية STATE محفوظة).
  - `advanceP6`: للجولات `identify` (D1) يمر عبر **3 خطوات** (`maxStep = 3`)؛ لجولات `sameordiff`/`close` (D2/D3) كشف واحد كالسابق (`maxStep = 1`).
  - `renderP6` (فرع D1): منطقة الإجابة تُبنى حسب الخطوة —
    - Step 1: الحرف فقط.
    - Step 2: + الاسم الصوتي (`باء — /b/`).
    - Step 3: + عدد الأصابع + صف النقاط الذهبية + موضع النقاط (`fact`).
  - زر المدرّس التالي يغيّر نصه: `كشف اسم الحرف ←` → `كشف الأصابع ←` → `التالي ←`.
  - التلميح العلوي يغيّر نصه لكل خطوة: `شغّل الصوت — اضغط Space لكشف الحرف` → `اضغط Space لكشف اسم الحرف` → `اضغط Space لكشف عدد الأصابع` → `اضغط Space للانتقال للسؤال التالي`.
  - `retreat` (←): يتراجع خطوة كشف واحدة في D1 ثم يطوي الإجابة ثم ينتقل للسؤال السابق (نمط `p3RevealStep`/`p5RevealStep` نفسه في المشروع).
  - `initP6` و`p6GoRound` يعيدان ضبط `p6RevealStep = 0`.

**CSS:**
- **Before:** لا تمييز بين خطوات الكشف.
- **After:** دخول متدرّج `p6RevealIn` لعناصر الإجابة مع تأخير متتالٍ (`reveal-step-3`: أصابع 0.05s ← نقاط 0.12s ← موضع 0.2s).
- **السبب:** التسلسل التربوي "استمع ← فكر ← استجب ← كشف المعلم ← تثبيت": الحرف أولاً، ثم اسمه، ثم تعزيز الأصابع/النقاط — والمعلم هو Controller الوحيد (بلا مؤقتات/تلقائي).

### 4.3 Task 3 — منطقة الإجابة كلوحة تعليمية

**CSS (`style.css`):**
- **Before:** `.p6-answer-zone.visible::before` = `'✓ الإجابة'`؛ لا نقاط ولا موضع داخل اللوحة.
- **After:**
  - label = `'✓ الإجابة الصحيحة'`.
  - إضافة `border-top: 2px solid rgba(201,162,39,0.35)` فوق تدرج gold/teal القائم (لون الهوية).
  - صف نقاط ذهبية `.p6-dots-row` يعيد استخدام `.dot-circle` القائمة (من P3/P4 — لا مكون جديد) بحجم أكبر `clamp(1.3rem, 3vw, 2rem)`.
  - `.p6-dot-fact` (سطر كامل): سهم موضع (فوق `☝` / أسفل `👇`) + نص الحقيقة مثل "نقطة واحدة أسفل الحرف".
- **السبب:** اللوحة تعزّز المعلومة بصرياً (عدد النقاط وموضعها) — وهي فكرة عدّ الأصابع نفسها — بألوان الهوية ودون لمس بيانات `lesson-01.js`.

### 4.4 Task 4 — الحفاظ على الهوية

- RTL والخطوط (Noto Sans/Naskh Arabic) وألوان الحروف (`--color-ba/ta/tha/nun` عبر inline من `renderP6`) والـ Classroom Stage كله كما هو — لم يُعد تصميم Layout نهائياً.
