## 1. الملخص

أُعيد بناء واجهة P6 (التمييز السمعي) من تخطيط "اختبار مضغوط" إلى **Auditory Training Classroom Stage** يملأ المسرح عمودياً ويقرأ كتمرين واحد من أعلى إلى أسفل:

```
رأس الحصة (تبويبات هادئة + تعليمات)
   ↓
الاستماع أولاً (منطقة التفاعل تتوسّع لتملأ المسرح)
   ↓
منطقة الإجابة (بعد الكشف)
   ↓
العداد (تقدم)
   ↓
أزرار المدرّس (كشف / التالي)
```

كل التغييرات في `css/style.css` فقط دون لمس DOM أو المنطق أو البيانات.

## 4. قواعد CSS المتغيرة (Before → After + السبب)

### 4.1 `.p6-container`
- **Before:** `width: min(100%, 1080px)`؛ gap `clamp(0.35rem,0.8vh,0.6rem)`؛ padding `clamp(0.25rem,0.7vh,0.5rem)`.
- **After:** `width: min(100%, 1180px)`؛ gap `clamp(0.5rem,1vh,0.85rem)`؛ padding `clamp(0.4rem,0.9vh,0.75rem)`.
- **السبب:** تقليل الفراغات الجانبية الميتة (المشكلة 4) وتحسين التوزيع الرأسي عبر نسب vh.

### 4.2 `.p6-main` — قلب التصميم
- **Before:** `display: grid` بعمودين، عرض `min(100%, 860px)`، جميع الأبناء `grid-column: 1/-1` (أي 860px في وعاء 1080px → فراغات جانبية كبيرة).
- **After:** `display: flex` (عمود)، عرض `min(100%, 1120px)`، `justify-content: center`.
- **السبب:** التخلص من الشبكة الزائفة (المشكلة 4) وتمكين إعادة الترتيب البصري عبر `flex order`.

### 4.3 التسلسل البصري (جديد — `flex order`)
- `.p6-play-zone / .p6-pair-zone / .p6-close-zone` → `order: 1` (الاستماع أولاً).
- `.p6-question-text` → `order: 2` (سؤال المقارنة يلتصق بمنطقة الاستماع).
- `.p6-answer-zone` → `order: 3` (الإجابة بعد الكشف).
- `.p6-counter` → `order: 4` (العداد بعد الإجابة — خطة المشروع: استمع ← فكر ← استجب ← كشف المعلم).
- `.p6-reveal-btn / .p6-next-btn` → `order: 5` (أزرار المدرّس في الأسفل).
- **السبب:** تحسين التسلسل البصري (Task 2) دون أي تغيير في ترتيب DOM الذي ينتجه `renderP6`.

### 4.4 مناطق الاستماع تتوسّع لتملأ المسرح
- `.p6-play-zone` و`.p6-pair-zone` و`.p6-close-zone` → `flex: 1 1 auto; min-height: 0` (قبل: `flex-shrink: 0`).
- **السبب:** المساحة الزائدة تذهب إلى منطقة التفاعل (البطل) بدل توزيعها كفجوات غير مبررة بين الأقسام؛ يملأ المسرح على 1280×720 / 1366×768 / 1920×1080 دون Scroll.

### 4.5 أحجام العناصر (Task 4 — المشكلة 3: عناصر صغيرة)
| العنصر | Before | After |
|---|---|---|
| زر D1 `.p6-big-play` | min-w `15–20rem`، min-h `5.5–8rem`، حد 2px | min-w `17–25rem`، ارتفاع `8–12.5rem`، حد 3px، خط أوضح |
| سؤال `.p6-question-text` | `1.1rem–fs-lg` | `clamp(1.35rem, 2.5vw, 2rem)` |
| حرف الإجابة `.p6-answer-char` | `2.6–5rem` | `3.2–6rem` |
| عدد الأصابع `.p6-answer-fingers` | `--fs-lg` | `clamp(1.5rem, 2.8vw, 2.1rem)` |
| اسم الحرف `.p6-answer-name` | `--fs-sm` | `clamp(1.1rem, 2vw, 1.45rem)` |
| بطاقتا D2 `.p6-pair-play` | min-w `10.25–13.5rem`، min-h `5.5–6.75rem` | min-w `11.5–15.5rem`، min-h `6.5–8.5rem` |
| فاصل D2 `.p6-pair-sep` | 2.7rem | 3.2rem |
| شارة نفس/مختلف `.p6-same-badge` | `1.1rem–fs-lg` | `clamp(1.5rem, 2.8vw, 2.1rem)` |
| بطاقات D3 `.p6-close-btn` | **min-w 100px فقط** | min-w `7.5–10.5rem`، min-h `5.5–7.5rem` |

- **السبب:** D3 لم يعد أصغر من أهمية النشاط (المشكلة البصرية 4 في التحليل)، وجميع العناصر مقروءة من الخلف.

### 4.6 هدوء التبويبات (Task 2 — المشكلة 5)
- `.p6-round-btn.active`: من تعبئة ذهبية كاملة (تنافس السؤال) إلى **خلفية ذهبية شفافة + نص ذهبي + حد ذهبي**؛ التبويب النشط أصبح مميزاً لكن غير صارخ.
- **السبب:** معلومات الجولة تأتي أخيراً في الأولوية البصرية دون التنافس مع منطقة الاستماع.

### 4.7 العداد
- **Before:** شارة شفافة بلا خلفية، `--fs-md` / `--fs-xs`.
- **After:** شارة بخلفية خفيفة وحدود، `clamp(1.4–1.9rem)` / `clamp(1–1.3rem)`.
- **السبب:** أوضح من الخلف دون أن يصبح عنصراً رئيسياً.

### 4.8 `@media (max-width: 900px)`
- `.p6-main { grid-template-columns: 1fr; }` → `.p6-main { width: 100%; }` (لأن `.p6-main` لم يعد grid).
- بقية قواعد الـ media query بقيت (`.p6-pair-zone` عمودي، `.p6-answer-zone` بعرض 100%...).
