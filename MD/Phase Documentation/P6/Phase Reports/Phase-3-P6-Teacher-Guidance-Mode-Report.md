## 1. الملخص

حوّل Phase 3 P6 من **نشاط جاهز للعرض** إلى **أداة تساعد المعلم على قيادة النشاط**، عبر شريط إرشاد صغير (Teacher Layer) يُدمج inline داخل رأس الحصة نفسه، يظهر فيه:

1. **مؤشر هدف الجولة** (تمييز الصوت / مقارنة صوتين / تمييز المتقاربة) — يعرف المعلم فوراً نوع النشاط قبل بدئه.
2. **مؤشر خطوة المعلم** (قبل التشغيل ← بعد التشغيل ← بعد الكشف) — يتحرك آلياً مع أفعال المعلم دون أي ضغطة إضافية.
3. **إرشاد عمل قصير** لكل جولة — جملة تنفيذية واحدة يوجّه بها الطلاب.
4. **فصل Teacher/Student Layers** — الشريط مُوسوم بـ"للمعلم" بتصميم هادئ خافت (خلفية شفافة + شريط teal جانبي) فلا يلفت انتباه الطلاب ولا ينافس منطقة التعلم.

**القرار المعماري الجوهري:** الإرشاد يجلس **inline مع الـ round-nav في رأس الحصة الموجود أصلاً** — لا صف/ترويسة جديدة، ولا أي زيادة في ارتفاع P6 على أي شاشة مستهدفة. الطالب يرى نفسه ما كان يراه تماماً (الصوت ← النشاط ← الإجابة)، والمعلم فقط يرى الهدف والخطوة التالية.

لم تُغيّر أي ID/class يعتمد عليها المشروع، ولم يُمَس `lesson-01.js` ولا `AudioManager` ولا الـ navigation ولا `lecture-01.html`.

## 4. التغييرات (Before → After + السبب)

### 4.1 Task 1 — مؤشر خطوة المعلم (قبل/بعد التشغيل/بعد الكشف)

**JS (`app.js`):**
- **Before:** المعلم لا يملك إشارة لحالته داخل الجولة — يعتمد على التعليمات الثابتة فقط.
- **After:**
  - `STATE.p6SoundPlayed: false` (حقل جديد فقط — بنية STATE محفوظة).
  - `p6PlaySound` يضع الحقل `true` ويحدّث نص الخطوة **في مكانه عبر DOM** (`p6UpdateGuideStepEl`) دون إعادة رسم كاملة — حتى لا تُمسح حالة "جارٍ الاستماع" المرسومة عبر CSS في Phase 2.
  - نص الخطوة من `p6GuideStepText(round)`:
    - **قبل التشغيل:** `شغّل الصوت` / `شغّل الصوتين` / `شغّل كل حرف` حسب الجولة.
    - **بعد التشغيل (قبل الكشف):** `ارفعوا الإصبع عند سماع الصوت` / `نفس الصوت أم مختلف؟` / `لاحظوا الفرق بين الأصوات`.
    - **بعد الكشف:** `الإجابة ظاهرة`.
  - إعادة ضبط الحقل عند: `initP6`، الانتقال لسؤال جديد، الانتقال لجولة جديدة، `p6GoRound`.
- **السبب:** المعلم Controller الوحيد — المؤشر يعكس حالته اللحظية (ما الذي يفعله الآن؟) فيتواصل مع الطلاب دون تردد.

### 4.2 Task 2 — مؤشر هدف الجولة

**JS (`app.js`):**
- **Before:** لا تمييز مرئي لنوع الجولة في رأس الحصة (التمييز فقط عبر تسمية تبويب الجولة).
- **After:** `P6_GUIDES` — جدول ثابت يربط `round.type` بهدف الجولة:
  - `identify` (D1) → `تمييز الصوت`
  - `sameordiff` (D2) → `مقارنة صوتين`
  - `close` (D3) → `تمييز المتقاربة`
  - يُقرأ من `round.type` الموجود — لا تعديل على بيانات `lesson-01.js`.
- **السبب:** يقرأ المعلم الهدف من نظرة واحدة قبل فتح الجولة.

### 4.3 Task 3 — إرشاد المعلم القصير لكل جولة

- **Before:** التعليمات الموجودة (`round.instruction`) نص ترحيبي للطلاب، لا يحدد فعل المعلم التنفيذي.
- **After:** `g.listen` في `P6_GUIDES` هو الإرشاد التنفيذي الذي يظهر **بعد تشغيل الصوت** (لحظة إدارة الاستجابة):
  - D1 → "ارفعوا الإصبع عند سماع الصوت"
  - D2 → "نفس الصوت أم مختلف؟"
  - D3 → "لاحظوا الفرق بين الأصوات"
- **السبب:** إرشاد واحد قصير في اللحظة الصحيحة (بعد السمع) — أوضح من تلميح دائم مزدحم.

### 4.4 Task 4 — فصل Student/Teacher Layers (شريط صغير خافت)

**CSS (`style.css`):**
- **Before:** كل ما يراه الطالب والمعلم في رأس الحصة شيء واحد.
- **After:** شريط `.p6-guide` يُميّز الـ Teacher Layer بصرياً عن الـ Student Layer:
  - خلفية شبه شفافة `rgba(255,255,255,0.045)` + حدود خافتة `rgba(176,190,197,0.16)`.
  - شريط جانبي teal (`border-inline-start: 3px solid var(--teal)`) — يعمل بالاتجاه الصحيح في RTL.
  - وسم `للمعلم` صغير خافت (`.p6-guide-role`).
  - الخط الأصغر في المشروع (`--fs-xs` وأصغر للوسم) — لا ينافس التعليمات الطلابية الكبيرة.
- **السبب:** "معلومات المعلم: هادئة، صغيرة، ثانوية" — يراها من يبحث عنها ولا تشتت الطلاب.

### 4.5 Task 5 — الحفاظ على الهوية (لغة بصرية)

- Navy/teal/gold (الوسم خافت، الهدف gold، الشريط الجانبي teal) + RTL + Noto (يرث `font-family` من الـ UI) — نفس أسلوب الرأس الحالي، بلا إعادة تصميم Layout.

## 6. تأكيد عدم تغيير المنطق/البيانات

- `js/lesson-01.js` (`discriminationRounds`/الحروف): **لم يُمس** — الهدف والإرشاد يُشتقان من `round.type` الموجود.
- `AudioManager` (`_cache`/`speak`/`playLetter`): **لم يُمس** — `p6PlaySound` لا يزال wrapper حول `p3PlaySound` (+تحديث حالة إرشاد فقط).
- نظام التنقل (`advance()`/`goToPhase`/باقي حالات `retreat`): **لم يُمس** — تعديل حالة P6 داخل `initP6`/`advanceP6`/`p6GoRound` فقط.
- بنية `STATE`: **لم تُحذف/تُهيكل** — أُضيف حقل واحد (`p6SoundPlayed: false`).
- `lecture-01.html`: **لم يُمس**.
- حالة "جارٍ الاستماع" (Phase 2): **محفوظة بالكامل** — إعادة رسم واحدة عند التشغيل كان ستمسحها؛ لذلك التحديث عبر `.p6-guide-step` في مكانه فقط.
- P7 (الذي يعيد استخدام `.p6-big-play`): سلوكه السابق محفوظ — لا يستدعي `p6PlaySound` فلا يُمسّ مؤشر P6.

## 7. توصيات مستقبلية (غير منفذة بعد)

1. **مؤشر انتظار استجابة الطلاب:** نبضة بصرية خفيفة على شريط الإرشاد (مثل `لحظة قصيرة من الصمت — انتظر استجابة الطلاب`) بعد "بعد التشغيل" — دون مؤقت تلقائي يقود الوتيرة.
