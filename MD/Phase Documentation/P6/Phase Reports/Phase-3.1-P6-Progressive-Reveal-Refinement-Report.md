# Phase 3.1 — P6 Progressive Reveal & Teacher Layer Refinement

> **التاريخ:** 2026-08-05
> **النطاق:** `css/style.css` + `js/app.js` فقط — مرحلة صقل (Refinement) لـ P6.
> **الملفات المحمية (لم تُلمس):** `lesson-01.js`، `AudioManager`، `lecture-01.html`، navigation architecture، بيانات الدرس، أي نشاط/مكوّن جديد.

---

## 1) Objective

استكمال نضج P6 كأداة تدريب سمعي صفّية عبر هدفين متكاملين:

1. **الكشف التدريجي الهادئ (Progressive Reveal):** تحويل إعادة الرسم المفاجئة عند كل خطوة كشف إلى "اكتشاف تدريجي" — عناصر الإجابة حاضرة دائماً في DOM، والظهور يُدار عبر CSS فقط (`opacity` + حركة خفيفة + توقيت متتابع هادئ) عبر `data-reveal-step`، فيتغيّر المظهر دون استبدال عناصر أو وميض إعادة بناء.
2. **تهدئة شريط المعلم (Teacher Layer Refinement):** تحويل `.p6-guide` إلى "معلومات تحكم" ثانوية خافتة — بلا حبة، بلا خلفية، بلا ذهب، بلا `letter-spacing` — يبقى مرجع المعلم لكنه لا ينافس واجهة الطالب التفاعلية.

الفلسفة المثبتة: **Listen → Think → Respond → Teacher Reveal → Fix Learning**. شريط المعلم يوجّه، والتبويبات هي الواجهة التفاعلية الوحيدة للطلاب.

## 3) Files Modified

### `Lesson-01-classroom-P6-Fixed\js\app.js` (1906 سطراً بعد المرحلة)

- **`p6ApplyReveal()`** (جديد، ~سطر 1356): helper واحد يطبّق حالة الكشف على DOM القائم — يحدّث `zone.dataset.revealStep` + `class visible` + زر المدرّس (`p6-reveal-btn`/`p6-next-btn`) + نص الزر + التلميح + إرشاد الخطوة — **دون إعادة رسم كاملة**.
- **`renderP6()`** (~1464): يخرج الآن **كل** عناصر الكشف حاضرة دائماً في DOM بوسوم `p6-reveal-item` و`r-char/r-name/r-fingers/r-dots/r-fact/r-result/r-chars/r-note`، مع `data-reveal-step` على `.p6-answer-zone`؛ `renderP6()` لا يُستدعى إلا عند تغيير سؤال/جولة.
- **`advanceP6()`** (~1420): الخطوات الداخلية الثلاث (حرف ← اسم ← أصابع+نقاط) عبر `p6ApplyReveal()`؛ إعادة الرسم فقط عند انتقال السؤال/الجولة/المرحلة.
- **`retreat()`** (~285، case P6): تراجُع الخطوات داخلياً عبر `p6ApplyReveal()`، وإعادة الرسم فقط عند الرجوع لسؤال/جولة سابقة.
- **لم يتغير** منطق D2/D3 (maxStep=1): النتيجة/الملاحظة تكشف في خطوة واحدة عبر نفس نظام التدرج (r-result+r-chars عند `!same`، وr-note لـ D3).

### `Lesson-01-classroom-P6-Fixed\css\style.css` (2982 سطراً بعد المرحلة)

- **`.p6-answer-zone`** (~2324): بطاقة تعليمية ثابتة الارتفاع `min-height: clamp(5.5rem, 12vh, 7.5rem)`؛ الحالة غير الظاهرة = `::before` "لوحة الإجابة" بخط خافت؛ الحالة الظاهرة (`.visible`) = حد علوي ذهبي `3px var(--gold)` + خلفية متدرّجة Navy + ظل.
- **نظام الكشف** (~2557–2590): `.p6-reveal-item` بـ `opacity:0; transform:translateY(12px) scale(0.94)` مع `transition` (بدل animation)؛ الرؤية عبر `[data-reveal-step="1|2|3"]`؛ تأخيرات متتابعة هادئة داخل الخطوة الواحدة (name 0.04s → fingers 0.1s → dots 0.18s → fact 0.26s).
- **`.p6-note-box`** (~2469): `flex: 0 1 auto; max-width:100%` — لا يدفع ارتفاع البطاقة.
- **`.p6-dot-fact`** (~2604): من `flex-basis:100%` إلى `flex: 0 1 auto; margin-inline-start:0.3rem` — يبقى inline في سطر الحرف/الأصابع.
- **`.p6-guide`** (~2623): شريط نصي هادئ — `margin-inline-start:0.5rem; padding-inline-start:0.7rem; border-inline-start:1px solid rgba(176,190,197,0.18)` فقط؛ role بخط `0.62rem` وopacity 0.7؛ purpose بـ `--text-secondary`؛ step بـ `--text-dim`. **كلها بلا `letter-spacing`.**

## 4) Visual Changes

**منطقة الإجابة:**
- قبل: تظهر عند الكشف بلا بنية واضحة + عناصر تحقن دفعة واحدة.
- بعد: بطاقة تعليمية هرمية — ترويسة ذهبية "الإجابة الصحيحة" ثم صف العناصر المكشوفة، بارتفاع ثابت فلا يتحرك التخطيط/الزر أثناء الكشف.
- الهوية: Navy/Teal/Gold محفوظة (خلفية Navy متدرجة + حد علوي ذهبي + نص ثانوي رمادي أزرق).

**الكشف:**
- قبل: `renderP6` كامل عند كل خطوة (وميض + قفز).
- بعد: عناصر قائمة تتحول من `opacity:0 / translateY(12px) scale(0.94)` إلى الظهور الكامل عبر انتقال `--dur-med`/`--dur-slow` و`--ease-out`/`--ease-spring` — تدرّج هادئ متتابع (0.04–0.26s) دون أي إعادة رسم.

**شريط المعلم:**
- قبل: حبة/خلفية/ذهب → يبدو كخيار نشاط.
- بعد: نص خافت فقط + فاصل رفيع `border-inline-start` — "معلومات تحكم" ثانوية بصرية واضحة، يُقرأ ولا يُضغط.

**معالجة الخط العربي:**
- أُزيل `letter-spacing` من كل نصوص P6 العربية المضبوطة (label "الإجابة الصحيحة"/"لوحة الإجابة"، وأجزاء `.p6-guide`) — لا كسر لاتصال الحروف.

## 5) Reveal — Before / After

### D1 (identify) — ثلاث خطوات يقودها المدرّس

| الخطوة | قبل | بعد |
|---|---|---|
| 0 (مخفي) | `لوحة الإجابة` | `لوحة الإجابة` — بلا تغيير بصري حقيقي |
| 1 | **إعادة رسم**: الحرف يُحقن | `data-reveal-step="1"` → الحرف يظهر فقط (r-char) |
| 2 | **إعادة رسم**: الاسم يُحقن | `data-reveal-step="2"` → + الاسم (r-name، تأخير 0.08s) |
| 3 | **إعادة رسم**: الأصابع+النقاط+الموضع | `data-reveal-step="3"` → + الأصابع (0.1s) + النقاط (0.18s) + الموضع (0.26s) |

كل عناصر `r-char/r-name/r-fingers/r-dots/r-fact` موجودة في DOM طوال الوقت؛ CSS فقط هي من يقرر الرؤية — **الإجابة تُكتشف ولا تُستبدل**.

### D2 (sameordiff) و D3 (close)

- `maxStep = 1`: الضغطة الأولى تعرض `data-reveal-step="1"`.
- D2: `r-result` (شارة نفس/مختلف) + `r-chars` (الحرفان عند الاختلاف) تظهران في الخطوة 1 (chars بتأخير 0.12s).
- D3: `r-note` (الملاحظة) تظهر في الخطوة 1.
- التراجُع: retreat يعيد الخطوات إلى الوراء عبر `p6ApplyReveal()` نفسها (step 3←2←1←0) بلا إعادة رسم.

## 6) Teacher Layer Refinement

- **الدور:** طبقة تحكم ثانوية هادئة — ليست خيار نشاط، وليست جزءاً من تجربة الطالب.
- **البنية:** نفس DOM Phase 3 (`p6-guide` inline داخل `round-nav`، بلا صف/ترويسة جديدة، بلا زيادة ارتفاع) — التغيير كله CSS.
- **التهدئة بالحذف لا الإضافة:** أُزيلت الحبة/الخلفية/الحدود الجانبية/الذهب/`letter-spacing`. الفصل البصري الآن عبر:
  - فاصل رفيع `border-inline-start: 1px solid rgba(176,190,197,0.18)`.
  - تدرّج لوني نصي فقط: role (0.62rem، opacity 0.7) → purpose (`--text-secondary`) → step (`--text-dim`).
- **محتوى المعلم محفوظ:** هدف الجولة (purpose من `round.type`) + خطوة المعلم الحية (before → listen → reveal عبر `STATE.p6SoundPlayed`/`p6AnswerVisible`، تُحدَّث في مكانها بـ `p6UpdateGuideStepEl()` دون مسح حالة "جارٍ الاستماع").
- **الطالب:** Student Layer كما كان تماماً — التبويبات هي الواجهة التفاعلية الوحيدة.

## 8) Architecture

```
p6-container
├── .p6-header
│   ├── .p6-round-nav ── round buttons (تبويبات الطلاب)
│   │       └── .p6-guide (Teacher Layer — Phase 3 + تهدئة 3.1)
│   └── .p6-instruction
├── .p6-main
│   ├── .p6-counter
│   ├── (نشاط الجولة): .p6-play-zone / .p6-pair-zone / .p6-close-zone
│   └── .p6-answer-zone[data-reveal-step="0..3"]   ← بطاقة تعليمية ثابتة الارتفاع
│       ├── .p6-reveal-item.r-char / .r-name / .r-fingers / .r-dots / .r-fact   (D1)
│       ├── .p6-reveal-item.r-result / .r-chars                                 (D2)
│       └── .p6-reveal-item.r-note                                              (D3)
└── .p6-controls ── .p6-reveal-btn ⇄ .p6-next-btn (تبديل CSS عبر class hidden)
```

**مبدأ الفصل:**
- **DOM:** ثابت عبر الكشف — منطقة الإجابة وعناصرها تُرسم مرة واحدة.
- **CSS:** وحدها تتحكم بالرؤية/الانتقال (`[data-reveal-step="0|1|2|3"]` + `.visible` + تأخيرات).
- **JS:** `p6ApplyReveal()` ينقل الحالة على DOM القائم للخطوات الداخلية/الرجوع؛ `renderP6()` فقط عند تغيير سؤال/جولة.
- **متغيرات التوقيت:** `--dur-med`/`--dur-slow`/`--ease-out`/`--ease-spring` — توقيت صفي هادئ (280–420ms) موحّد مع بقية الحصة.

**الحدود المحترمة:** لا بيانات درس جديدة، لا نشاطات/مكونات/تيمر/سكورينغ، لا لمس لـ `lesson-01.js`/AudioManager/navigation/`lecture-01.html`.

## 9) Recommendations

1. **اختبار صفي على بروجكتور:** 720p (الأهم) ثم 1366×768/1920×1080 — تأكيد بلا Scroll وقصّ وتوسّع Layout أثناء الكشف الثلاثي.
2. **تأكيد سماع التدرّج:** انتقال الخطوة 3 (الأصابع → النقاط → الموضع بتأخير 0.1–0.26s) يُعطي الإيقاع الهادئ المطلوب دون إبطاء الدرس.
3. **متابعة مقترحات Phase 3 المعلّقة** (خارج نطاق 3.1): مؤشر انتظار الاستجابة + حالة اختيار صوتي D3 — كمرحلة لاحقة منفصلة.
4. **التحقق من الاتساق:** أي مرحلة كشف مستقبلية (P5/P7) قد تستفيد من نفس نمط `data-reveal-step` + ارتفاع ثابت بدل إعادة الرسم.
5. **`letter-spacing`:** القاعدة ملزمة الآن — لا يُستخدم مع نصوص عربية في أي إضافة مستقبلية.
