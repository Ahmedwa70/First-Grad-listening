# External Benchmark Analysis

## المصدر الخارجي

**صندوق التجويد للأطفال** — محتوى تعليمي مجاني، ملف HTML تفاعلي واحد، يعمل offline على كمبيوتر وموبايل، بدون اشتراك أو إعلانات. يغطي مخارج الحروف وأحكام التجويد عبر 3 مستويات (مبتدئ / متوسط / متقدم).

---

## الأفكار القابلة للاستفادة

### 1. الأنشطة التفاعلية
- ألعاب مطابقة وتصنيف وترتيب داخل الدرس نفسه.
- التنويع بين أنماط التفاعل (سحب، اختيار، ترتيب) يكسر رتابة الكشف التدريجي الخطي.

### 2. التدريب الصوتي
- استماع + تدريب صوتي كنشاط مستقل (ليس فقط تشغيل ملف صوتي).
- ربط السماع بفعل (رفع أصابع، تصنيف، مقارنة) — وهو ما يفعله P6 حالياً لكن بشكل محدود.

### 3. مستويات التعلم
- تقسيم المحتوى إلى مبتدئ / متوسط / متقدم داخل نفس الموضوع.
- يسمح للمعلم باختيار مستوى الصعوبة حسب الطلاب.

### 4. التقييم والمراجعة
- نقاط ونجوم وإنجازات ومستويات كتحفيز.
- تحديات مراجعة دورية — ليس فقط تقييم نهائي (P7).
- اختبارات قصيرة بين الأنشطة.

### 5. مكتبة تعليمية مستقبلية
- نموذج "الصندوق" = وحدة تعليمية مستقلة قابلة للتكرار.
- بناء مكتبة من صناديق/محاضرات مستقلة تعمل offline.
- كل وحدة HTML واحدة مكتفية ذاتياً.

| الفكرة | الحالة في المشروع |

## Benchmark: Letter Learning System Analysis

### المصدر
**آية كيدز (AyaKids)** — قسم "التعرف على الحروف". تطبيق تعليمي عربي للأطفال. الصورة تظهر نظام Letter Profile مع tabs للحركات (فتحة / ضمة / كسرة) + صفحة "تعرف على الحروف" لعرض جميع الحروف الـ 28.

### الأفكار القابلة للاستفادة

| الفكرة | الوصف | التوافق مع المشروع |
|--------|-------|---------------------|
| Letter Profile (ملف الحرف) | كل حرف له صفحة مستقلة تجمع: الشكل، الصوت، كلمة مثال، صورة توضيحية | يتوافق مع Letter Object في `lesson-01.js` ومع AMLSA (طبقات متعددة لكل حرف) |
| Tabs حسب الحركة | تنظيم الحرف بـ فتحة/ضمة/كسرة كـ tabs — نفس الحرف بأصوات مختلفة | يتوافق مع AMLSA Layer 1 (Audio) — الحرف كوحدة صوتية متعددة الأشكال |
| شبكة مراجعة كاملة | عرض جميع الحروف الـ 28 في grid واحد للمراجعة السريعة | يشبه P3 Quad View لكن لـ 28 حرفاً بدل 4 — مفيد في Template Extraction |
| ربط حرف-كلمة-صورة | كل حرف مربوط بكلمة مثال + صورة توضيحية (جَمَل، بِنْت) | يتوافق مع P5 (الحروف في الكلمات) — الصور غير موجودة حالياً |

### ما هو موجود بالفعل

| عنصر AyaKids | المقابل في المشروع |
|--------------|---------------------|
| شكل الحرف + اسمه | `letter.char` + `letter.name` في Letter Object |
| صوت الحرف | `letter.audioFile` + AudioManager + P2 |
| كلمة مثال | `word.word` + `word.chars` في P5 |
| عرض مقارن لعدة حروف | P3 Quad View + P4 Compare View |
| تقدم بين الحروف | Progress Dots في P3/P6/P7 |

### تطوير مستقبلي فقط

| الفكرة | السبب |
|--------|-------|
| Letter Profile كصفحة مستقلة لكل حرف | يحتاج Template Extraction + بنية تنقل جديدة — لا يناسب classroom-first حيث المعلم يتحكم بالتسلسل |
| Tabs حركات (فتحة/ضمة/كسرة) | يحتاج توسيع Letter Object بحقول `phonemeWithFatha`/`phonemeWithDamma`/`phonemeWithKasra` — تغيير DATA schema |
| صور توضيحية للكلمات | يحتاج أصول صور + حقل `imageFile` في Word Object — تغيير DATA schema |
| شبكة 28 حرفاً للمراجعة | يحتاج بيانات 28 حرفاً — حالياً 4 فقط. ينتظر Template Extraction |

### ما لا يناسب المشروع حالياً

| عنصر | السبب |
|------|-------|
| تجربة ذاتية للطفل (Self-paced) | المشروع classroom-first — المعلم يتحكم بالوتيرة، الطالب لا يتنقل بنفسه |
| واجهة موبايل أساسية | المشروع projector-first — الشاشة الكبيرة هي المنصة الأساسية |
| تنقل حر بين الحروف | يتعارض مع Progressive Reveal — المعلم يكشف تدريجياً حسب الخطة التربوية |
| نظام إنجازات فردي | لا يناسب بيئة الفصل — التقييم جماعي عبر المعلم (P7 scores) |
