## 01 — الاستراتيجية التعليمية
### المنطلقات الفكرية والفلسفة والنهج التعليمي

### لماذا هذا المنهج للطلاب الصينيين تحديدًا؟

**السياق الثقافي والتربوي**

- الصينية لغة نبرية — العربية لغة حركية: الطالب يحتاج تدريبًا صوتيًا صريحًا لأن الصينية لا تعتمد على حركات الحروف أصلًا
- الكتابة الصينية تعكس المعنى لا الصوت: الحرف العربي يمثّل صوتًا — هذا مفهوم جديد تمامًا يحتاج بناءً تدريجيًا مدروسًا
- الطلاب الصينيون اعتادوا التعلم الحفظي: المنهج التواصلي يكسر هذا النمط ويُنشّط الدماغ بطريقة مختلفة تمامًا
- الإحراج الاجتماعي شائع: بيئة المجموعة والألعاب تخفّف الضغط النفسي وتشجع على المخاطرة والكلام

---

### المحاور الاستراتيجية الخمسة

**◉ 1 — الصوت أولًا دائمًا**
الحرف ← الصوت ← الكلمة ← الجملة — لا يُعرض الحرف قبل سماع صوته. الطالب يخمّن الحرف بعد سماع الصوت

**◉ 2 — التواصل الفوري**
حوار حقيقي منذ المحاضرة الأولى ولو بكلمة واحدة. الفائدة الآنية = الدافعية المستمرة

**◉ 3 — التغذية الراجعة الفورية**
كل إجابة تحصل على لون + صوت + شرح في أقل من نصف ثانية. لا أسئلة بلا تصحيح فوري

**◉ 4 — التكرار التراكمي**
كل محاضرة = 5 دقائق مراجعة ما سبق + إضافة جديدة. الحروف السابقة تُراجَع في كل درس

**◉ 5 — المتعلم في المركز**
70٪ من وقت الفصل نشاط طلاب — المعلم يُصمّم البيئة ولا يُلقي المعلومة

### نسبة الوقت المثلى في كل محاضرة

| النشاط | المدة | النسبة | الهدف |
|--------|-------|--------|-------|
| المراجعة التراكمية | 8-10 دقائق | 8٪ | ربط الجديد بالسابق — تثبيت الذاكرة طويلة المدى |
| التقديم والشرح | 15-20 دقيقة | 14٪ | تقديم الحرف أو المهارة بالصوت والصورة فقط |
| التدريب الموجَّه | 30-35 دقيقة | 27٪ | أنشطة فردية وثنائية بإشراف المعلم |
| التواصل الحر | 25-30 دقيقة | 23٪ | حوار حقيقي أو لعبة تعليمية بدون توجيه |
| التقييم والإغلاق | 10-15 دقيقة | 10٪ | 5-10 أسئلة سريعة + شرح الواجب |
| **مجموع التطبيق الفعلي** | **~100 دقيقة** | **≥73٪** | الطالب يتكلم ويكتب ويتفاعل |

## 02 — مراحل البرنامج
### الهيكل التعليمي للستة عشر محاضرة

### خريطة المراحل الأربعة

**المرحلة الأولى │ الأصوات والحروف الأساسية — المحاضرات 1-4**
- **الهدف:** اكتساب أول 16 حرفًا وربطها بأصواتها وأشكالها الأربعة وبناء أول كلمات حقيقية
- **المخرج الرئيسي:** يقرأ الطالب الحروف الـ16 بالحركات الثلاث ويسمّي أغراض الفصل بجمل قصيرة

**المرحلة الثانية │ الكلمة والجملة الأولى — المحاضرات 5-8**
- **الهدف:** بناء الكلمات وتكوين جمل تعارف كاملة وإجراء أول حوار حقيقي مستقل
- **المخرج الرئيسي:** يتعارف الطالب مع زملائه بـ6 تبادلات ويتبادل الأرقام ويذكر أيام الأسبوع

**المرحلة الثالثة │ علامات الضبط والقراءة — المحاضرات 9-12**
- **الهدف:** إتقان الشدة والتنوين واللام الشمسية والقمرية والمدود للوصول لقراءة مستقلة
- **المخرج الرئيسي:** يقرأ الطالب نصًا جديدًا من 5 جمل لم يرَه قبلًا بدقة 75٪ فأكثر

**المرحلة الرابعة │ التواصل والتكامل — المحاضرات 13-16**
- **الهدف:** توظيف كل المهارات في قراءة نصوص وكتابة متصلة وحوار حر موسّع
- **المخرج الرئيسي:** يُجري الطالب حوارًا تعارف كاملًا ويكتب فقرة صحيحة ويقرأ نصًا مستقلًا

## 03 — هيكل ملف HTML
### الأقسام العشرة الثابتة في كل محاضرة

> **مبدأ الاتساق:** كل ملف HTML يتبع نفس الهيكل العشاري لضمان تجربة متسقة للطالب. التسلسل ثابت — المحتوى يتغير حسب هدف المحاضرة. مدة الملف الكاملة: 45-60 دقيقة للاستخدام المنزلي أو تكملة لأنشطة الفصل.

| # | القسم | الوصف |
|---|-------|-------|
| **1** | **رأس الصفحة** — ثابت في كل درس | شريط علوي بلون المحاضرة + الرقم + العنوان + شريط التقدم (1-16) + هدف المحاضرة في سطر واحد — يُريح الطالب ويُشعره بأين هو في الرحلة |
| **2** | **المراجعة السريعة** — أول 5 دقائق | بطاقات الحروف السابقة — الطالب ينقر البطاقة فيسمع الصوت ويصحح نفسه — عشوائية في كل مرة — لا يُكمَل الدرس بدون 70٪ في المراجعة |
| **3** | **التقديم الصوتي** — قبل ظهور الحرف | زر تشغيل الصوت قبل ظهور الحرف — الطالب يكتب الحرف الذي يعتقده في حقل نصي — الإجابة الصحيحة تظهر بعد 3 ثواني |
| **4** | **الحرف التفاعلي** — قلب الدرس | عرض الحرف بحجم 120px+ بأشكاله الأربعة (أول/وسط/آخر/منفرد) + animation النطق + مقارنة مرئية بالحروف المتشابهة |
| **5** | **تدريب النطق** — تكرار موجَّه | أزرار المقاطع — click → سماع الصوت — الطالب يكرر — بالحركات الثلاث حسب المرحلة — سرعة قابلة للتعديل |
| **6** | **الكلمات والصور** — ربط بالمعنى | بطاقات الكلمة + الصورة + الصوت — مطابقة drag-and-drop أو اختيار متعدد — تغذية فورية بالألوان والصوت |
| **7** | **الجمل الحية** — التراكيب الأولى | جملة رئيسية تُبنى كلمة كلمة مع animation — الطالب يقرأ جهرًا ثم يسمع النموذج — ثلاثة مستويات: بطيء/عادي/سريع |
| **8** | **نشاط التواصل** — القلب التفاعلي | يتغير حسب المحاضرة: محاكاة حوار / بينغو / لعبة التمييز / Canvas الكتابة / مشغّل النص — وقت أطول من باقي الأقسام |
| **9** | **تقييم ختامي** — 5-10 دقائق | 5-10 أسئلة سريعة متنوعة الصيغ (سمعي/بصري/كتابي) — نتيجة فورية — زر "كرر النشاط الضعيف" — شارة النجاح عند 80٪+ |
| **10** | **الواجب والتالي** — إغلاق الدرس | كارت الواجب بصيغة واضحة + ملخص ما تعلّمته اليوم + زر الانتقال للمحاضرة التالية + حفظ التقدم في localStorage |

## 04 — المبادئ التقنية
### القواعد غير القابلة للتفاوض في كل ملف

**🔊 الصوت قبل الحرف — دائمًا**
لا يُعرض شكل الحرف قبل سماع صوته. استخدم Web Audio API أو `<audio>` tags مع ملفات mp3 مُسجَّلة للحرف والكلمة والجملة — لهجة فصحى واضحة وبطيئة قليلًا

**🌐 RTL حقيقي — ليس شكليًا**
`direction: rtl; text-align: right` على الـ body كاملًا. الجداول تبدأ من اليمين. أرقام الصفحات والعدادات تُعكس. اختبر على Safari وAndroid ليس فقط Chrome

**🔤 الحرف بحجم مرئي كبير**
120px كحد أدنى حين يكون الحرف هو محور الدرس — 80px للحروف في جدول المقارنة. استخدم خطًا عربيًا واضحًا: Noto Naskh Arabic أو Cairo

**⚡ تغذية راجعة في 0.5 ثانية**
إجابة صحيحة → أخضر `#22C55E` + صوت إيجابي قصير. خاطئة → أحمر `#EF4444` + اهتزاز + شرح الإجابة الصحيحة. لا تأخير إطلاقًا

**📱 Mobile-first — أولوية الهاتف**
الطلاب الصينيين يستخدمون الهاتف. كل عنصر قابل للنقر بالإصبع (44px minimum touch target). اختبر على شاشة 390px عرض. Font-size: 16px+ لمنع zoom التلقائي

**💾 حفظ التقدم بين الجلسات**
localStorage لحفظ: الحروف التي أتقنها الطالب + نتائج الاختبارات + آخر محاضرة وصل إليها. يتيح للطالب المتابعة من حيث توقف

**🔄 التكرار التراكمي مبرمَج**
أول قسم في كل ملف = مراجعة الحروف السابقة كلها بترتيب عشوائي. الحروف التي فشل فيها الطالب تظهر أكثر (Spaced Repetition مبسّط)

**📊 مؤشر التقدم المرئي**
شريط (1-16) في رأس كل صفحة — يُريح الطالب ويُشعره بالتقدم الفعلي. دائرة نسبة الإتقان (٪) تتحدث بعد كل قسم

---

### معايير الجودة — قبل نشر أي ملف

| المعيار | المتطلب | أداة الاختبار |
|---------|---------|--------------|
| الصوت | كل حرف وكلمة وجملة لها ملف صوت mp3 يعمل | افتح الملف وانقر كل زر صوت |
| RTL | كل النصوص تظهر من اليمين بشكل صحيح | Chrome DevTools → Emulation → Arabic locale |
| Touch | كل الأزرار قابلة للنقر باليد دون تكبير | اختبر على هاتف حقيقي أو Mobile emulator |
| التغذية الراجعة | كل إجابة لها رد فوري بالصوت واللون | أجب بإجابات خاطئة وتحقق من الرد |
| التقدم | نتيجة التقييم تُحفظ عند الخروج والعودة | افتح → أجب → أغلق → أعد الفتح |
| الأداء | الصفحة تُحمَّل في أقل من 3 ثواني على 3G | Chrome Lighthouse → Mobile |

## 05 — خريطة المحاضرات

| **9** | **الشدة — حرفان في واحد** ◎ يميّز المشدّد وغير المشدّد | لعبة 1 أو 2: صوت → الطالب يضغط الزر الصحيح |
| **10** | **التنوين — نهايات الأسماء** ◎ يقرأ الأسماء المنوّنة | البطاقات الثلاثية الملوّنة: حمراء/صفراء/خضراء |

| **12** | **المدود — الإطالة الصوتية** ◎ يميّز القصير من الطويل | visualizer: موجة صوتية قصيرة / موجة ممتدة مرئية |
| **13** | **أول نص كامل** ◎ يقرأ نصًا ويُعيد روايته | مشغّل النص: تظليل كلمة كلمة مع الصوت — 3 سرعات |
| **14** | **الكتابة المتصلة** ◎ يكتب كلمات متصلة صحيحة | Canvas للتتبع + لوحة كتابة حرة مع مقارنة overlay |
| **15** | **حوار حر موسّع** ◎ يُجري 8-10 تبادلات حرة | محاكاة حوار متقدمة: أسئلة متنوعة بمستويات صعوبة |
| **16** | **الاختبار النهائي والاحتفاء** ◎ قياس كل المهارات | شهادة إنجاز مخصّصة: اسم الطالب + درجته + الطباعة |

### أكثر الأخطاء شيوعًا عند البناء

**❌ نسيان RTL في الـ JavaScript**
حين تُضيف نصًا عربيًا بـ `innerHTML` أو `textContent` تأكد من الـ `dir="rtl"` على العنصر الأب

**❌ حجم الصوت صغير جدًا**
سجّل الأصوات في بيئة هادئة بـ 48kHz. المسافة من الميكروفون: 20-30 سم

**❌ الـ drag-and-drop على الهاتف**
استخدم مكتبة touch-events أو pointer events API بدلًا من HTML5 drag API وحده

**❌ localStorage لا يعمل في Safari private mode**
أضف `try/catch` حول كل عمليات localStorage مع fallback لـ session storage

**❌ animation سريعة جدًا**
الطالب المبتدئ يحتاج وقتًا. animation الحرف يجب ألا تقل عن 600ms

**❌ عدم اختبار الخط العربي على Windows**
بعض خطوط العربية تبدو مختلفة على Windows. استخدم web font محدد ولا تعتمد على النظام
