## 01  تعريف الوثيقة ودورها في المنظومة

تقع هذه الوثيقة في المرتبة السابعة من منظومة وثائق المشروع، وهي تمثل نقطة التحول من التخطيط إلى التنفيذ. الوثائق الست السابقة أجابت عن "لماذا" و"ماذا"؛ أما هذه الوثيقة فتجيب عن "كيف" — وبشكل محدد ونهائي لا يحتمل الاجتهاد.

### 1.1  لماذا نحتاج هذه الوثيقة؟

- وثيقة Instructional Blueprint تصف ما يجب أن يحدث تربوياً — لكنها لا تُحدد المكونات التقنية المقابلة لكل فعل.  ◆
- وثيقة HTML Architecture تصف كيف نبني النظام عموماً — لكنها لا تُطبّق هذا على المحاضرة الأولى تحديداً.  ◆
- دون هذه الوثيقة، سيضطر المطور إلى اتخاذ قرارات تربوية بنفسه أثناء الكتابة — وهذا انتهاك صريح لفلسفة المشروع.  ◆
- هذه الوثيقة تُغلق كل باب للاجتهاد التقني على حساب الجودة التربوية.  ◆

## 02  خريطة التحويل العامة

| **العنصر التربوي** | **العنصر التنفيذي داخل HTML** |

## 03  الخريطة الكاملة للمحاضرة الأولى — مرحلة بمرحلة

ما يلي خريطة التنفيذ الكاملة للمحاضرة الأولى. كل مرحلة تمثل Section مستقلة داخل lecture-01.html.

### P1 — افتتاح الدرس  |  0–10 دقائق

| **الهدف التعليمي** | تأسيس البيئة الآمنة، الإجابة عن "ما هذه اللغة؟"، كسر الحاجز العاطفي، تهيئة الطلاب للتعلم الصوتي. |
| --- | --- |
| **ما يظهر على الشاشة** | عنوان الدرس (الحروف الأربعة بخط كبير). نص ترحيبي. حقل الأبجدية العربية (28 حرفاً) مع دائرة تُبرز الأربعة المستهدفة. معلومة التوجيه (اتجاه القراءة). |
| **المكونات المستخدمة** | م-07 (كشف تدريجي) — م-17 (لافتة المرحلة) — م-18 (شريط التقدم) |
| **الأنشطة** | ن-00 (الافتتاح): عرض هوية الدرس + نشاط اكتشاف الاتجاه |
| **تحكم المعلم** | Space لكشف عنوان الدرس. ضغطة ثانية لإظهار حقل الأبجدية. ضغطة ثالثة لتمييز الحروف الأربعة. |
| **حالة الصفحة — البداية** | جميع محتوى P1 مخفي. شاشة كحلية نظيفة مع لافتة المرحلة فقط. |
| **حالة الصفحة — النهاية** | حقل الأبجدية مرئي بالكامل. الحروف الأربعة مُضاءة. باقي الحروف بتباين 30%. |
| **شرط الانتقال** | المعلم يُشغّل نشاط P2 بضغطة واحدة. لا شرط أداء. |

### P2 — الصوت أولاً  |  10–25 دقيقة

| **الهدف التعليمي** | ترسيخ التمثيل الصوتي للأصوات الأربعة قبل رؤية الحرف المكتوب. قاعدة: الفونيم يسبق الغرافيم. |
| --- | --- |
| **ما يظهر على الشاشة** | شاشة شبه فارغة: أيقونة متحدث كبيرة في المركز + أيقونة عد الأصابع (1–4). لا حروف مرئية. |
| **المكونات المستخدمة** | م-05 (زر الكشف الصوتي) — م-06 (إشارة الترديد الجماعي) |
| **الأنشطة** | ن-01 (الاستماع الصامت) — ن-02 (الترديد الجماعي) — ن-03 (عد الأصوات بالأصابع) — ن-04 (التصحيح الصوتي للثاء) |
| **تحكم المعلم** | ضغطة لتشغيل كل صوت. ضغطة ثانية لإشارة الترديد. الترتيب: ب → ت → ث → ن. يُعيد الصوت بلا حد. |
| **حالة الصفحة — البداية** | لا حروف مرئية على الشاشة. أيقونة المتحدث في الحالة الهادئة. |
| **حالة الصفحة — النهاية** | أربعة أصوات مؤكَّدة سمعياً. لافتة P2 تُشير "الصوت مكتمل". لا شكل مكتوب بعد. |
| **شرط الانتقال** | المعلم يُشغّل P3 يدوياً بعد التأكد من استجابة الطلاب الجماعية للأصوات. |

### P3 — كشف الحروف  |  25–40 دقيقة

| **الهدف التعليمي** | ربط كل صوت (مُرسَّخ في P2) بشكله المكتوب. التعرف البصري الأول على الحروف الأربعة. |
| --- | --- |
| **ما يظهر على الشاشة** | بطاقة حرف واحدة تظهر في المركز (كشف تدريجي). الحرف بخط كبير مع اسمه وصوته. عند اكتمال الحروف: عرض رباعي للمقارنة. |
| **المكونات المستخدمة** | م-01 (بطاقة الحرف) — م-05 (زر الصوت) — م-07 (كشف تدريجي) — م-06 (إشارة ترديد) — م-12 (مطابقة) |
| **الأنشطة** | ن-05 (كشف الحرف ×4) — ن-06 (رفع البطاقة الجماعي) — ن-07 (الاستجابة الفردية) |
| **تحكم المعلم** | Space لكشف كل حرف جديد. ضغطة الصوت لتشغيل اسم الحرف. S للإضاءة الموجَّهة على الحرف المُعلَّم. |
| **حالة الصفحة — البداية** | شاشة كحلية نظيفة. بطاقات الحروف في الحالة المخفية. |
| **حالة الصفحة — النهاية** | أربع بطاقات حروف في الحالة الكاملة (Full). عرض رباعي للحروف المتشابهة. |
| **شرط الانتقال** | المعلم يرى أن الصف يُجيب على رفع البطاقة بدقة ≥70%. الانتقال لـP4. |

### P4 — لعبة النقاط  |  40–55 دقيقة

| **الهدف التعليمي** | عزل النقطة كعامل مُميِّز وحيد. الطالب يُدرك أن الشكل الأساسي واحد والفارق هو النقاط فقط. |
| --- | --- |
| **ما يظهر على الشاشة** | الشكل الأساسي بلا نقاط في المركز (كبير جداً 128+ بكسل). نقاط قابلة للسحب في الجانب. بعد الإكمال: حرف مكتمل ومقارنة رباعية. |
| **المكونات المستخدمة** | م-04 (طبقة النقاط) — م-11 (سحب وإسقاط النقاط) — م-08 (إضاءة موجَّهة) — م-09 (محدد عشوائي) |
| **الأنشطة** | ن-08 (استكشاف القاسم المشترك) — ن-09 (التحدي الفردي — السبورة) — ن-10 (سباق النقاط الثنائي) — ن-11 (ورقة العمل الرقمية) |
| **تحكم المعلم** | ضغطة لتقديم الشكل الأساسي. R لإضافة النقاط دفعةً واحدة (طارئ). S للإضاءة على الحرف المُشكِل. H للمسح وإعادة البداية. |
| **حالة الصفحة — البداية** | الشكل الأساسي بلا نقاط. النقاط الأربع في حالة مخفية على اليسار (ستُسحب). |
| **حالة الصفحة — النهاية** | الحروف الأربعة مكتملة بنقاطها. عرض مقارن. ورقة العمل مُنجزة. |
| **شرط الانتقال** | المعلم يتحقق من دقة ≥70% في وضع النقاط قبل الانتقال لـP5a. |

### P5a — تقديم المفردات  |  55–75 دقيقة

| **الهدف التعليمي** | ربط الحروف المعروفة بكلمات حاملة للمعنى. بناء مثلث: صوت ← حرف ← معنى. |
| --- | --- |
| **ما يظهر على الشاشة** | بطاقة كلمة واحدة في المركز: صورة + كلمة بتشكيل كامل + ترجمة صينية + أيقونة صوت. بعد الأربع: عرض رباعي. |
| **المكونات المستخدمة** | م-02 (بطاقة الكلمة) — م-05 (صوت الكلمة) — م-07 (كشف) — م-09 (محدد عشوائي) — م-01 (مرجع الحرف) |
| **الأنشطة** | ن-12 (تقديم الكلمة بالصورة والصوت ×4) — ن-13 (القراءة الصفية بالتناوب) — ن-14 (مؤشر الكلمة العشوائي) |
| **تحكم المعلم** | Space لكشف كل كلمة. ضغطة الصوت لتشغيل النطق. 9 لتشغيل المحدد العشوائي. S للإضاءة على الكلمة المطلوبة. |
| **حالة الصفحة — البداية** | بطاقات الكلمات الأربع في الحالة المخفية. الحروف الأربعة في الحالة المتراجعة (ركن الشاشة). |
| **حالة الصفحة — النهاية** | الكلمات الأربع (باب/بيت/نار/ثوب) في الحالة الكاملة. الطالب يقرأ كل كلمة عند الإشارة. |
| **شرط الانتقال** | المعلم يتحقق من استجابة الصف للمحدد العشوائي بدقة ≥70% قبل الانتقال لـP5b. |

### P5b — إنتاج الجملة  |  75–100 دقيقة

| **الهدف التعليمي** | إنتاج الجملة العربية الأولى من الواقع. الانتقال من التعرف إلى الإنتاج الفعلي. |
| --- | --- |
| **ما يظهر على الشاشة** | شريط الجملة في المركز: "هَذَا بَاب" و"هَذَا بَيْت". الكلمات تظهر تباعاً. صورة الجسم الحقيقي (باب/بيت). مؤقت للعمل الثنائي. |
| **المكونات المستخدمة** | م-03 (شريط الجملة) — م-05 (صوت الجملة) — م-10 (مؤقت) — م-06 (إشارة الترديد) |
| **الأنشطة** | ن-15 (تقديم الجملة بالسياق الحقيقي) — ن-16 (الترديد بالإشارة والتناوب) — ن-17 (العمل الثنائي: قل وأشِر) — ن-18 (العكس الإدراكي) |
| **تحكم المعلم** | Space لكشف كلمة الجملة تباعاً. T لتشغيل مؤقت العمل الثنائي (8 دقائق). Space+S للانتقال بين الجملتين. صوت الجملة الكاملة بضغطة واحدة. |
| **حالة الصفحة — البداية** | شريط الجملة مخفي. الكلمات المكوِّنة في الحالة المتراجعة. |
| **حالة الصفحة — النهاية** | الجملتان مكتملتان وكل طالب أنتج واحدة منهما في العمل الثنائي. |
| **شرط الانتقال** | المعلم يُلاحظ إنتاج ≥65% من الأزواج للجملة بشكل صحيح. الانتقال لـP6a. |

### P6a — سباق التوطيد  |  100–108 دقائق

| **الهدف التعليمي** | ترسيخ الاسترجاع الآلي لجميع الحروف والكلمات المتعلَّمة في المحاضرة بإيقاع سريع. |
| --- | --- |
| **ما يظهر على الشاشة** | بطاقات سريعة تتبدل كل 3 ثوانٍ تلقائياً بعد تشغيل المعلم. الحروف الأربعة + الكلمات الأربع مخلوطة. مؤقت كبير (96 بكسل) في الزاوية. |
| **المكونات المستخدمة** | م-01 (بطاقات الحروف) — م-02 (بطاقات الكلمات) — م-07 (كشف سريع) — م-10 (مؤقت) |

| **حالة الصفحة — النهاية** | جولتان كاملتان من 8 بطاقات. السباق منتهٍ. المؤقت وصل للصفر. |

### P6b — التقويم الختامي  |  108–118 دقيقة

| **الهدف التعليمي** | التحقق من الاستيعاب الفردي. الإملاء الصامت. جملة الخروج الإجبارية. |

### P7 — الإغلاق والواجب  |  118–120 دقيقة

## 04  خريطة تنفيذ كل نشاط في المحاضرة الأولى

### ن-01 — الاستماع الصامت
