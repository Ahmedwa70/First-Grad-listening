**أنشطة المرحلة الأولى — التوجيه والترحيب**  

  **النشاط 1.1 — الاستقبال والبيئة الآمنة**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | يدخل الطالب الفصل في حالة نفسية منفتحة ومنخفضة القلق |
| **الهدف المعرفي** | تفعيل مخطط الفضول قبل تقديم أي محتوى |
| **الهدف اللغوي** | تعرّض سمعي أول لكلمة عربية حقيقية: مرحبًا |
| **المواد** | لا شيء — المعلم هو الوسيلة الوحيدة |
| **إجراءات المعلم** | 1. يقف عند الباب ويرحّب بكل طالب بـ"مرحبًا" مع ابتسامة.  2. بعد جلوس الجميع يكتب "مرحبًا" على اللوح.  3. يقول: "هذه الكلمة التي سمعتموها للتو — هذا شكلها بالعربية." |
| **إجراءات الطالب** | يجلس ويراقب. لا يُطلب منه أي فعل. |
| **الاستجابات المتوقعة** | فضول بصري تجاه شكل الكلمة، بعض الطلاب يُحاولون نطقها همساً |
| **الأخطاء المتوقعة** | لا توجد — لا نشاط ناتج بعد |
| **التغذية الراجعة الفورية** | لا تصحيح. المعلم يُعزّز جو الترحيب فقط. |
| **نقطة التقييم** | لا تقييم رسمي — يُلاحظ مستوى الانتباه البصري |
| **معيار النجاح** | جميع الطلاب جالسون ومنتبهون بحلول الدقيقة الثالثة |
| **الانتقال إلى 1.2** | "هل تعرفون كيف تُقرأ هذه الكلمة؟ من أي اتجاه؟" |

 

  **النشاط 1.2 — اكتشاف اتجاه القراءة**  

| **المدة** | 4 دقائق |
| --- | --- |
| **الهدف التعلمي** | يُحدّد الطالب باستقلالية أن العربية تُقرأ من اليمين إلى اليسار |
| **الهدف المعرفي** | تحفيز الاكتشاف قبل الشرح — تناقض المخطط المعرفي الصيني/الإنجليزي |
| **الهدف اللغوي** | لا هدف لغوي — تهيئة فضائية |
| **المواد** | كلمة "مرحبًا" على اللوح + ورقة توجيه مطبوعة (سطر عربي مع سهم) |
| **إجراءات المعلم** | 1. "هل نقرأ من هنا؟" (يُشير لليسار) "أم من هنا؟" (يُشير لليمين).  2. ينتظر 10 ثوانٍ.  3. يمشي من اليمين نحو اليسار وأصبعه يتبع الكتابة.  4. يوزّع ورقة التوجيه — الطلاب يتتبعون السطر بأصابعهم. |
| **إجراءات الطالب** | يُخمّن، يراقب، يتتبع السطر بالإصبع على الورقة المطبوعة |
| **الاستجابات المتوقعة** | تخمينات متباينة — بعضهم يقول يسار (أثر الصينية والإنجليزية) |
| **الأخطاء المتوقعة** | تتبع السطر من اليسار إلى اليمين |
| **التغذية الراجعة الفورية** | يضع يده الهادئة فوق يد الطالب ويُعيد التوجيه من اليمين — لا تصحيح لفظي |
| **نقطة التقييم** | يمشي بين المقاعد ويُلاحظ اتجاه تتبع الأصابع |
| **معيار النجاح** | ≥ 85% يتتبعون السطر من اليمين إلى اليسار بعد التوجيه |
| **الانتقال إلى 1.3** | يكشف عن ورقة الحروف الـ28: "هذا ميدان اللغة العربية. اليوم سنتعلم 4 منها فقط." |

 

  **النشاط 1.3 — حقل الحروف البصري**  

| **المدة** | دقيقتان |
| --- | --- |
| **الهدف التعلمي** | يرى الطالب حجم الأبجدية كاملاً ويُدرك أنه يتعلم جزءاً منها فقط اليوم |
| **الهدف المعرفي** | تقليل الإرهاق المعرفي عبر تحديد حدود المهمة |
| **الهدف اللغوي** | لا هدف لغوي محدد |
| **المواد** | ملصق الحروف الـ28 أو عرض مرئي |
| **إجراءات المعلم** | 1. يعرض الـ28 ويسأل: "كم حرفاً تتوقعون؟"  2. يكشف الرقم 28.  3. يُدوّر دائرة على الحروف الأربعة (ب ت ث ن).  4. "هذه هي مهمة اليوم كاملة." |
| **إجراءات الطالب** | مراقبة — لا نشاط مطلوب |
| **الاستجابات المتوقعة** | ارتياح واضح عند تحديد المهمة في 4 حروف فقط |
| **الأخطاء المتوقعة** | لا توجد |
| **التغذية الراجعة الفورية** | لا تغذية راجعة |
| **نقطة التقييم** | لا تقييم |
| **معيار النجاح** | الطلاب ينظرون إلى الحروف الأربعة المُحدَّدة ببؤرة انتباه واضحة |
| **الانتقال إلى 1.4** | "28 حرفاً تكفي للتحدث مع 400 مليون إنسان." |

| **المدة** | دقيقة واحدة |
| --- | --- |

| **الهدف المعرفي** | تحفيز الدافعية الذاتية (Intrinsic Motivation) عبر المعنى |
| **الهدف اللغوي** | لا هدف لغوي محدد |

**أنشطة المرحلة الثانية — الصوت أولاً**  

  **النشاط 2.1 — الاستماع الصامت**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | يُشكّل تمثيلاً صوتياً نقياً لكل من الأصوات الأربعة دون تشويش الشكل المرئي |
| **الهدف المعرفي** | الترميز الصوتي المعزول (Isolated Phonological Encoding) |
| **الهدف اللغوي** | تمييز الفونيمات: /ب/ /ت/ /ث/ /ن/ |
| **المواد** | صوت المعلم فقط — لا أدوات |
| **إجراءات المعلم** | 1. يطلب إغماض الأعين.  2. ينطق /ب/ ببطء مع مبالغة في إغلاق الشفتين — صمت 3 ثوانٍ.  3. /ت/ مع لمس خلف الأسنان.  4. /ث/ مع إخراج اللسان.  5. /ن/ مع الأنين الأنفي. |
| **إجراءات الطالب** | إغماض العيون — استماع فقط — لا ترديد |
| **الاستجابات المتوقعة** | حركات شفاه صامتة، ابتسامات عند صوت الثاء |
| **الأخطاء المتوقعة** | فتح العيون — يُطلب بهدوء إعادة إغلاقها |
| **التغذية الراجعة الفورية** | لا تصحيح — التركيز على خلق الانغماس الصوتي |
| **نقطة التقييم** | يُلاحظ حركات الشفاه للتحقق من الانتباه |
| **معيار النجاح** | الطلاب صامتون ومنتبهون طوال الـ3 دقائق |
| **الانتقال إلى 2.2** | "افتحوا أعينكم. سنقول هذه الأصوات معاً الآن." |

 

  **النشاط 2.2 — الترديد الجماعي المتدرج**  

| **المدة** | 5 دقائق |
| --- | --- |
| **الهدف التعلمي** | ينتج الأصوات الأربعة شفهياً في بيئة جماعية لا تُعرّضه فردياً |
| **الهدف المعرفي** | بناء الثقة عبر الإنتاج المحمي (Choral Production) |
| **الهدف اللغوي** | نطق صحيح مقبول للأصوات: /ب/ /ت/ /ث/ /ن/ |
| **المواد** | صوت المعلم — إشارات يدوية |
| **إجراءات المعلم** | 1. يرفع يده إشارةً للاستماع — ينطق /ب/ — يُحرّك يده للأمام إشارةً للترديد.  2. إصبع للأعلى = أعلى صوتاً / للأسفل = أهدأ.  3. يُكرر مع الأصوات الثلاثة.  4. يُغيّر الترتيب.  5. يُكرر دورة كاملة. |
| **إجراءات الطالب** | مراقبة الإشارة — ترديد جماعي — تعديل الصوت وفق الإشارة |
| **الاستجابات المتوقعة** | صوت جماعي قوي — بعض الطلاب يُبالغون في الحماس |
| **الأخطاء المتوقعة** | خلط /ت/ بـ/د/ — يُرجع الإصبع للشفتين دون كلام |
| **التغذية الراجعة الفورية** | التغذية حركية فقط (إشارات اليد). لا تصحيح لفظي فردي. |
| **نقطة التقييم** | يستمع لجودة الترديد الجماعي ككتلة — ليس لأفراد |
| **معيار النجاح** | الترديد الجماعي مسموع وموحَّد في ≥ 80% من الدورات |
| **الانتقال إلى 2.3** | "الآن ستساعدونني في اكتشاف شيء. استعدوا — سأقول صوتاً واحداً فقط." |

 

  **النشاط 2.3 — لعبة عدّ الأصوات بالأصابع**  

| **المدة** | 4 دقائق |
| --- | --- |
| **الهدف التعلمي** | يُميّز الأصوات الأربعة سمعياً دون دعم بصري باستخدام أصابعه رمزاً |
| **الهدف المعرفي** | تعزيز التمييز الصوتي (Phonemic Discrimination) بالتشفير الحركي |
| **الهدف اللغوي** | تمييز الفونيمات في بيئة استقبال خالصة |
| **المواد** | لا أدوات — الأصابع فقط |
| **إجراءات المعلم** | الاتفاقية: ب=1 / ت=2 / ث=3 / ن=4.  ينطق صوتاً — ينتظر 4 ثوانٍ — يرفع الإصبع الصحيح.  يُكرر 8 مرات عشوائياً. |
| **إجراءات الطالب** | يستمع — يُفكّر — يرفع عدد الأصابع المقابل — يُقارن مع المعلم |
| **الاستجابات المتوقعة** | نسبة إجابات صحيحة 60–75% في الجولة الأولى |
| **الأخطاء المتوقعة** | الخلط بين ث (3 أصابع) وت (2 إصبع) — الأكثر شيوعاً |
| **التغذية الراجعة الفورية** | يرفع الإصبع الصحيح — يُشير لموضع النطق للصوت المرتبك |
| **نقطة التقييم** | AC-2: إذا كانت الدقة < 70% في الجولة الثانية → توقف وعودة لـ2.2 |
| **معيار النجاح** | ≥ 70% يرفعون الإصبع الصحيح في ≥ 6 من 8 جولات |
| **الانتقال إلى 2.4** | "الثاء هذا صعب — دعونا نُصلحه معاً بطريقة واحدة." |

 

  **النشاط 2.4 — التصحيح الصوتي للثاء**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | ينتج صوت الثاء /θ/ باستخدام التوجيه الحركي (لسان بين الأسنان) |
| **الهدف المعرفي** | تجاوز الفجوة الصوتية عبر التعلم الجسدي (Embodied Cognition) |
| **الهدف اللغوي** | إنتاج مقبول لصوت الثاء — ليس مثالياً بالضرورة |
| **المواد** | مرآة صغيرة اختيارية — أو كاميرا الهاتف |
| **إجراءات المعلم** | 1. يُخرج لسانه برفق بين أسنانه وينفخ هواءً — يُكرر.  2. يدعو الطلاب لتكرار الحركة أمام المرايا.  3. ينطق /ث/ صحيحاً 3 مرات — الطلاب يُرددون. |
| **إجراءات الطالب** | يُقلّد حركة اللسان — ينطق أمام المرآة — يردد جماعياً |
| **الاستجابات المتوقعة** | ضحك ودّي، إحراج إيجابي، تحسّن خلال دقيقتين |
| **الأخطاء المتوقعة** | نطق /س/ بدل /ث/ — يُشير لإخراج اللسان مجدداً |
| **التغذية الراجعة الفورية** | لا يُصحّح فرداً أمام المجموعة. يُعزّز للصف كله إذا سمع التحسّن. |
| **نقطة التقييم** | يُلاحظ هل اللسان يظهر عند الطلاب أم لا |
| **معيار النجاح** | ≥ 60% ينتجون صوتاً قريباً من /θ/ بحلول نهاية النشاط |
| **الانتقال إلى 3.1** | "ممتاز. الآن ستشاهدون هذه الأصوات — كيف تبدو مكتوبة؟" |

 

**أنشطة المرحلة الثالثة — ربط الصوت بالحرف**  

  **النشاط 3.1 — الكشف التدريجي عن الحرف**  

| **المدة** | 5 دقائق |
| --- | --- |
| **الهدف التعلمي** | يربط كل صوت سبق تشفيره بشكله المكتوب — حرف واحد في كل مرة |
| **الهدف المعرفي** | تجنب التشبّع البصري بعرض الحروف الأربعة دفعةً واحدة |
| **الهدف اللغوي** | اكتساب الوصلة الصوت–رمز (Phoneme–Grapheme Correspondence) |
| **المواد** | بطاقات كبيرة A3 — حرف واحد لكل بطاقة — محجوبة في البداية |
| **إجراءات المعلم** | 1. يُمسك بطاقة ب مقلوبة — ينطق /ب/ — يكشفها ببطء.  2. "هذا هو شكله." — يتبعها بيده من اليمين لليسار.  3. يُعيد الكشف 3 مرات.  4. يُكرر مع ت وث ون. |
| **إجراءات الطالب** | ينتبه — يُردد الصوت عند الكشف — يُتابع حركة اليد |
| **الاستجابات المتوقعة** | تعجّب بصري عند رؤية الحرف لأول مرة |
| **الأخطاء المتوقعة** | لا توجد — هذا نشاط استقبالي |
| **التغذية الراجعة الفورية** | تعزيز إيجابي جماعي عند الترديد الصحيح |
| **نقطة التقييم** | لا تقييم رسمي — تعريفي |
| **معيار النجاح** | الطلاب يُرددون الصوت عند كشف الحرف في ≥ 90% من الكشوفات |
| **الانتقال إلى 3.2** | "الآن كلنا سنكتب هذه الحروف... في الهواء." |

 

  **النشاط 3.2 — التتبع الهوائي للحرف**  

| **المدة** | 4 دقائق |
| --- | --- |
| **الهدف التعلمي** | يُشفّر شكل الحرف في الذاكرة الحركية (Procedural Memory) |
| **الهدف المعرفي** | التشفير الحركي (Kinaesthetic Encoding) لتثبيت شكل الحرف |
| **الهدف اللغوي** | تمثيل حركي صحيح لتسلسل رسم الحروف الأربعة |
| **المواد** | البطاقات الكبيرة |
| **إجراءات المعلم** | 1. يرفع البطاقة.  2. يرسم الحرف في الهواء بإصبعه ببطء مبالغ فيه — 3 مرات.  3. يطلب من الطلاب الرسم معه.  4. يُكرر كل حرف 3 مرات. |
| **إجراءات الطالب** | يرسم الحرف في الهواء بإصبعه — يُتابع اتجاه المعلم |
| **الاستجابات المتوقعة** | حركة متزامنة مع المعلم — بعضهم يُعيد الرسم بمبادرة ذاتية |
| **الأخطاء المتوقعة** | الرسم من اليسار إلى اليمين — يُشير للمبدأ ويُعيد بصمت |
| **التغذية الراجعة الفورية** | حركية — يُعيد الرسم ببطء أكبر إذا رأى خطأً |
| **نقطة التقييم** | يُلاحظ اتجاه الرسم لعدد من الطلاب |
| **معيار النجاح** | ≥ 75% يرسمون من اليمين إلى اليسار |
| **الانتقال إلى 3.3** | يوزّع البطاقات الصغيرة (حرف لكل طالب): "خذوا. هذه بطاقاتكم." |

 

  **النشاط 3.3 — رفع البطاقة الجماعي**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | يُقيَّم تعرف الطالب على الحرف صوتياً دون ضغط التحدث الفردي |
| **الهدف المعرفي** | تقييم التعرف (Recognition) لا التذكر (Recall) في مرحلة آمنة |
| **الهدف اللغوي** | التحقق من الوصلة الصوت–رمز في الاتجاهين |
| **المواد** | بطاقات صغيرة A5 بالحروف الأربعة |
| **إجراءات المعلم** | "عندما أنطق الصوت — ارفعوا البطاقة الصحيحة." ينطق /ب/ — ينتظر 4 ثوانٍ — يرفع البطاقة الصحيحة. يُكرر 8 مرات عشوائياً. |
| **إجراءات الطالب** | يُفتّش بين بطاقاته — يرفع المناسبة — يُقارن مع المعلم |
| **الاستجابات المتوقعة** | دقة 70–85% في الجولة الأولى |
| **الأخطاء المتوقعة** | الخلط بين ب وت (النقطة الواحدة مقابل النقطتين) — الأكثر حدوثاً |
| **التغذية الراجعة الفورية** | يرفع البطاقة الصحيحة دون تعليق — الطلاب يُصحّحون أنفسهم بصرياً |
| **نقطة التقييم** | AC-3: إذا كانت الدقة < 70% في الجولة الثانية → نشاط إضافي للحرف المُشكِل |
| **معيار النجاح** | ≥ 75% يرفعون البطاقة الصحيحة في ≥ 6 من 8 جولات |
| **الانتقال إلى 3.4** | "سأسأل الآن واحداً منكم. كن مستعداً." |

 

  **النشاط 3.4 — الاستجابة الفردية السريعة**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | ينتج اسم الحرف شفهياً بشكل فردي لأول مرة |
| **الهدف المعرفي** | الانتقال من التعرف الجماعي إلى الإنتاج الفردي في بيئة محدودة المخاطر |
| **الهدف اللغوي** | إنتاج اسم الحرف شفهياً: باء / تاء / ثاء / نون |
| **المواد** | البطاقات الكبيرة |
| **إجراءات المعلم** | 1. يرفع بطاقة ويُشير لطالب عشوائياً: "ما هذا؟"  2. ينتظر 5 ثوانٍ.  3. إذا لم يُجِب: يُشير لجاره.  4. يدور على 4–5 طلاب. |
| **إجراءات الطالب** | ينطق اسم الحرف — أو يُشير لجاره إذا لم يعرف |
| **الاستجابات المتوقعة** | معظم الطلاب ينتجون الاسم الصحيح — بعضهم يتردد |
| **الأخطاء المتوقعة** | اسم خاطئ — يُعيد النطق الصحيح مرةً واحدة دون تعليق |
| **التغذية الراجعة الفورية** | "نعم — باء." أو: يُعيد الاسم الصحيح مرة وينتقل. لا توقف ممتد. |
| **نقطة التقييم** | يُلاحظ الطلاب الذين لم يستطيعوا الإجابة ويُدوّن أسماءهم |
| **معيار النجاح** | ≥ 80% من الطلاب المختارين ينتجون الاسم الصحيح |
| **الانتقال إلى 4.1** | "هذه الحروف الأربعة — لها شيء مشترك جداً. من يُخبرني؟" |

 

**أنشطة المرحلة الرابعة — لعبة النقاط**  

  **النشاط 4.1 — استكشاف القاسم المشترك**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | يكتشف باستقلالية أن الشكل الأساسي واحد والفارق هو النقاط فقط |
| **الهدف المعرفي** | التعلم بالاكتشاف (Discovery Learning) ينتج فهماً أعمق من التلقّي |
| **الهدف اللغوي** | تعزيز التمييز البصري البنيوي للحروف |
| **المواد** | الحروف الأربعة جنباً إلى جنب على السبورة |
| **إجراءات المعلم** | 1. يكتب: ب ت ث ن.  2. ينتظر 10 ثوانٍ بصمت.  3. "ما الذي تلاحظون؟"  4. يُدوّر دائرة على الشكل الأساسي.  5. "الشكل واحد — النقاط هي كل شيء." |
| **إجراءات الطالب** | يُراقب — يُفكّر — يُشارك بملاحظة |
| **الاستجابات المتوقعة** | "النقاط مختلفة" — "الشكل نفسه" — "المنحنى واحد" |
| **الأخطاء المتوقعة** | الانتباه للنقاط فقط دون رؤية الشكل الأساسي |
| **التغذية الراجعة الفورية** | كل إجابة صحيحة جزئياً تُقبل وتُكمَّل: "نعم — وأيضاً..." |
| **نقطة التقييم** | يستمع لنوعية الملاحظات |
| **معيار النجاح** | ≥ 3 طلاب يُشيرون للنقاط كعامل تمييز قبل أن يتدخل المعلم |
| **الانتقال إلى 4.2** | "من يريد أن يأتي للسبورة ويُجرّب؟" |

 

  **النشاط 4.2 — التحدي الفردي على السبورة**  

| **المدة** | 5 دقائق |
| --- | --- |
| **الهدف التعلمي** | يطبّق المعرفة التحليلية عملياً بإضافة النقاط الصحيحة على الشكل الأساسي |
| **الهدف المعرفي** | التطبيق (Application) في بيئة اجتماعية — الأقران محكّمون |
| **الهدف اللغوي** | التمييز الدقيق: ب (1 تحت) / ت (2 فوق) / ث (3 فوق) / ن (1 فوق مع قوس أعمق) |
| **المواد** | السبورة — الطباشير أو الماركر |
| **إجراءات المعلم** | 1. يرسم الشكل الأساسي بلا نقاط.  2. يُسمّي حرفاً.  3. طالب يتطوع — يُضيف النقاط.  4. "هل هذا صحيح؟" — الصف يُحكم.  5. يُكرر مع الحروف الثلاثة. |
| **إجراءات الطالب** | يأتي للسبورة — يُضيف النقاط — الصف يُقيّم |
| **الاستجابات المتوقعة** | نقاط الباء صحيحة في الغالب — الثاء أكثر خطأً |
| **الأخطاء المتوقعة** | نقاط بالعدد الخاطئ أو الموضع الخاطئ |
| **التغذية الراجعة الفورية** | الصف يُحكم أولاً — المعلم يُؤكّد أو يُصحّح بعد الصف |
| **نقطة التقييم** | AC-4: إذا تجاوزت أخطاء النقاط 40% → نشاط علاجي (قاعدة الأرض) |
| **معيار النجاح** | ≥ 70% يضعون النقاط بعدد ومكان صحيح |
| **الانتقال إلى 4.3** | "الآن منافسة! طالبان في نفس الوقت." |

 

  **النشاط 4.3 — سباق النقاط الثنائي**  

| **المدة** | 4 دقائق |
| --- | --- |
| **الهدف التعلمي** | يعمّق التمييز بين الحروف تحت ضغط زمني خفيف في بيئة تنافسية آمنة |
| **الهدف المعرفي** | الضغط الزمني الإيجابي يرسّخ الاسترجاع السريع دون قلق |
| **الهدف اللغوي** | استرجاع فوري لنمط نقاط كل حرف |
| **المواد** | السبورة — مساحتان منفصلتان |
| **إجراءات المعلم** | 1. يرسم شكلين أساسيين متجاورين.  2. يُسمّي حرفاً.  3. طالبان يكتبان في نفس الوقت.  4. الأسرع والأصح يفوز.  5. الصف يُحكم.  6. يُكرر 4 جولات. |

| **الاستجابات المتوقعة** | إثارة وتشجيع — ضحك ودّي |

| **نقطة التقييم** | ملاحظة غير رسمية للدقة والسرعة |

| **الانتقال إلى 4.4** | "الآن أنتم وحدكم. ورقة عمل — دقيقتان." |

 

  **النشاط 4.4 — ورقة عمل النقاط الذاتية**  

| **المدة** | 3 دقائق |
| --- | --- |

| **الهدف المعرفي** | التشفير الذاتي (Self-Encoding) يطوّل الاحتفاظ |

**أنشطة المرحلة الخامسة — الكلمة والجملة**

| **الانتقال إلى 5.2** | "الآن أنتم تقرؤون — صف بصف." |

 

  **النشاط 5.2 — القراءة الصفية بالتناوب**  

| **المدة** | 5 دقائق |
| --- | --- |
| **الهدف التعلمي** | ينتج الكلمة المكتوبة شفهياً بشكل متدرج من الجماعي إلى الصفي |
| **الهدف المعرفي** | التدريج من الحماية الجماعية إلى المحاسبة الصفية الجزئية |
| **الهدف اللغوي** | قراءة بطيئة صحيحة للكلمات الأربع |
| **المواد** | الكلمات الأربع على السبورة — بدون صور |
| **إجراءات المعلم** | 1. يُزيل الصور — تبقى الكلمات فقط.  2. يُلوّح للصف الأول — يقرؤون جماعياً.  3. يُكرر مع الصف الثاني والثالث.  4. يُعيد الدورة بكلمات مختلفة. |

| **الانتقال إلى 5.3** | "الآن لن أعرف أي كلمة سأشير إليها. استعدوا." |

 

  **النشاط 5.3 — مؤشر الكلمة العشوائي**  

| **المدة** | 3 دقائق |
| --- | --- |
| **الهدف التعلمي** | يُقيَّم التعرف الفوري على الكلمة دون اعتماد على التسلسل المتوقع |
| **الهدف المعرفي** | الاسترجاع غير المتسلسل (Non-Sequential Retrieval) أقوى من الترتيب الثابت |
| **الهدف اللغوي** | قراءة فورية للكلمات الأربع في أي ترتيب |
| **المواد** | السبورة — مؤشر |
| **إجراءات المعلم** | 1. يُشير لأي كلمة عشوائياً.  2. ينتظر 3 ثوانٍ.  3. إذا قرأ الصف: "ممتاز."  4. إذا لم يقرأ: يقول الكلمة ثم يُشير مجدداً.  5. يُكرر 8 مرات. |
| **إجراءات الطالب** | ينتبه باستمرار — يقرأ متى يُشير المعلم |
| **الاستجابات المتوقعة** | إثارة الانتظار — تسابق خفيف |

  **القسم السادس — خطط استعادة الفشل  (Failure Recovery)**  

 

*هذه الخطط ليست "إعادة الشرح". كل خطة نشاط بديل محدد يعالج جذر الصعوبة لا ظاهرتها.*

 

**ف.1 — صعوبة التمييز بين الحروف المتشابهة (ب/ت/ث/ن)**

◆  العَرَض: الطالب يخلط بين الحروف الأربعة عند الاختبار السريع

◆  السبب الجذري: لم تُرسَّخ النقاط كمُمَيِّز رئيسي بعد

◆  النشاط العلاجي — الحرف المريض: يرسم حرفاً ناقص النقاط: "هذا الحرف مريض — من يُعالجه؟" الطالب يُضيف النقاط. يُكرر مع الحروف المُشكِلة فقط. (3–4 دقائق)

◆  الموضع: يُدرَج مباشرة بعد اكتشاف المشكلة — يُستبدل بالدقائق الأولى من النشاط التالي

 

**ف.2 — صعوبة النطق (صوت الثاء)**

◆  العَرَض: الطالب ينطق /س/ بدلاً من /ث/

◆  السبب الجذري: الصوت غائب في اللغة الأم — لم تُرسَّخ الحركة الحركية

◆  النشاط العلاجي — المرآة الثلاثية: ثلاثة طلاب يجلسون أمام بعض ويُراقب كل منهم لسان الآخر عند النطق. المراقبة الاجتماعية تُصحّح الحركة. (3 دقائق في بداية المحاضرة التالية)

 

**ف.3 — صعوبة الاتجاه (القراءة من اليسار)**

◆  العَرَض: الطالب يتتبع الكلمة من اليسار إلى اليمين باستمرار

◆  السبب الجذري: الترميز الحركي للقراءة اليسارية راسخ جداً

◆  النشاط العلاجي — الأصبع الأحمر: مشيرة ملوّنة يتتبع بها السطر قبل القراءة. اللون يُعيد التركيز على الحركة اليدوية. يُطبَّق في كل نشاط قرائي دون وقت إضافي.

 

**ف.4 — صعوبة النقاط (عدد أو موضع خاطئ)**

◆  العَرَض: يكتب 2 نقاط للثاء أو يضع نقطة الباء فوق بدلاً من تحت

◆  السبب الجذري: لم تُميَّز قاعدة "تحت = باء" كمرتكز ذهني

◆  النشاط العلاجي — قاعدة الأرض: "الباء تنام على الأرض — نقطتها تحتها كالوسادة." الطالب يُكرر الجملة مع رسم الحرف. (دقيقتان في توجيهات الواجب)

 

**ف.5 — صعوبة القراءة (الكلمات لا تُقرأ دون صور)**

◆  العَرَض: يقرأ الكلمة فقط عندما تكون الصورة المقابلة ظاهرة

◆  السبب الجذري: الربط لا يزال بصرياً — الصوت المعزول غير مُرسَّخ

◆  النشاط العلاجي — خفاء الصورة التدريجي: يُغطي الصورة بورقة تدريجياً حتى تختفي — الطالب يستمر في القراءة. التخفيض التدريجي (Fading) يُرسّخ الاستقلالية. (4 دقائق بديلاً عن 5.3)
