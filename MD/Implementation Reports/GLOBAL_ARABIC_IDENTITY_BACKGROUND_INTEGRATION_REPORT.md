# Global Arabic Identity Background Integration Report

## Executive Summary

تمت إضافة **طبقة هوية عربية هندسية عالمية واحدة** على مستوى التطبيق كاملاً عبر CSS فقط. تعمل الطبقة كخلفية علامة تجارية هادئة خلف المحتوى التعليمي وواجهة المعلم، ولا تدخل في التخطيط أو حسابات Grid/Flex أو التفاعل.

لم يتم تعديل JavaScript أو بيانات الدروس أو بنية DOM أو أي مكوّن قائم. كما لم يتم تغيير ألوان العناصر التعليمية أو حالات التفاعل أو الحركات.

## موضع الطبقة في المعمارية

وضعت الطبقة على العنصر الجذر `#app` عبر pseudo-element واحد:

```text
Application Root (#app)
├── ::before — Global Arabic Identity Background Layer (z-index: 0)
├── Teacher HUD (z-index: 1)
├── Lesson Content / #content-zone (z-index: 1)
├── Teacher Controls (z-index: 1)
└── Progress Rail (z-index: 1)
```

هذا الموضع يحقق تغطية موحدة لكل مراحل الدرس، من دون إدراج عناصر HTML إضافية أو نسخ الخلفية داخل كل صفحة. كما أن `pointer-events: none` يمنع الطبقة من اعتراض أي نقر أو تفاعل.

## سبب اختيار `#app`

يمثل `#app` الجذر الفعلي لمنطقة العرض، ويضم HUD المعلم ومنطقة محتوى الدرس وأشرطة التحكم والتقدم. لذلك يتيح استخدام `#app::before` طبقة واحدة متسقة تغطي التطبيق كاملاً، بدلاً من الاعتماد على حاويات داخلية متغيرة العرض مثل `.p2-container`.

تم تعطيل طبقة P2 المحلية السابقة (`#content-zone:has(.p2-container)::before`) لمنع تكرار النقوش في المرحلة الثانية. أصبحت الخلفية العالمية هي المصدر الوحيد للهوية المشتركة، بينما تبقى البطاقات والمكونات نفسها دون إعادة تصميم.

## إعدادات المظهر

| الوضع | opacity | أسلوب اللون | مبدأ العرض |
|---|---:|---|---|
| **Light Mode** | `0.010` | رمادي/أزرق بارد منخفض التباين | أثر ورقي عربي فاخر بالكاد يلاحظ. |
| **Dark Mode** | `0.014` | تركواز وذهبي منخفضا الشدة | هوية عربية هادئة من دون Glow أو لمعان. |

النمط ثابت، غير متحرك، وغير تفاعلي. وهو موضوع خلف جميع طبقات المحتوى، ولذلك لا يقع فوق البطاقات أو حالات hover أو active.

## التحقق الفني

أظهر فحص الطبقات الحي أن pseudo-element الخلفية يعمل بـ`z-index: 0` و`pointer-events: none`، في حين تعمل منطقة المحتوى وTeacher HUD بـ`z-index: 1`. وفي الوضع الليلي بقي الفونيم النشط في P2 واضحاً باللون `#F8FAFC`، مع بقاء منطقة الدرس من دون تمرير.

تمت مراجعة المراحل السبع في جلسة واحدة؛ وكان ارتفاع منطقة المحتوى ثابتاً (`clientHeight = scrollHeight = 993px` في الجلسة المختبرة) لكل المراحل P1–P7.

## معيار القبول

تمت المحافظة على التسلسل البصري المطلوب:

> المحتوى التعليمي الحالي ← حالة التفاعل الحالية ← أدوات المعلم ← الهوية العربية الخلفية.

تظل الخلفية محسوسة فقط عند النظر المتأني، بينما يرى المعلم المحتوى التعليمي أولاً خلال ثلاث ثوانٍ من العرض. لذلك تحققت طبقة هوية عربية عالمية هادئة من دون تشتيت أو أثر على فلسفة «الصوت أولاً».
