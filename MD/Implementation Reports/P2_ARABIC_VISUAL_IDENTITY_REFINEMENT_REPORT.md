# P2 Arabic Visual Identity Refinement Report

## Scope

تم توسيع الهوية الهندسية العربية الخفيفة في خلفية منطقة P2 عبر CSS فقط. يعمل النمط الآن كحقل بصري محيط بمنطقة التدريب، مع قناع مركزي يقلل ظهوره خلف بطاقات الأصوات حتى تبقى منطقة الفونيمات أنظف نقطة تركيز في الشاشة.

لم تتم إضافة عناصر HTML، ولم يتغير JavaScript أو ترتيب المحتوى أو منطق النشاط أو بيانات الدرس.

## التعديل المنفذ

| العنصر | التنفيذ | الأثر البصري |
|---|---|---|
| **الحقل الهندسي العام** | إضافة طبقة خلفية CSS باستخدام خطوط هندسية متقاطعة بدرجات Teal وGold منخفضة الشدة. | تمد الهوية العربية إلى المناطق الفارغة الجانبية بدلاً من حصرها في مساحة صغيرة. |
| **الوضع النهاري** | استخدام `opacity: 0.032` مع تدرج شعاعي يخفي النقوش نسبياً خلف منطقة البطاقات. | تظهر الهوية كإحساس بصري خفيف، لا كعنصر مستقل ينافس النصوص. |
| **الوضع الليلي** | خفض الشدة إلى `opacity: 0.018`. | يحافظ على هدوء الخلفية الداكنة ويمنع منافسة الفونيم أو شارة الصوت. |
| **حماية منطقة البطاقات** | استخدام `mask-image` بقيمة شفافية منخفضة في المركز وأوضح قليلاً عند الأطراف. | تبقى البطاقات والفونيمات أنظف منطقة في الصفحة. |
| **التفاعل** | الطبقة الخلفية `pointer-events: none` ولا تؤثر على الأزرار أو التحكم. | لا يتغير سلوك المعلم أو منطق النقر. |

## أثر التعديل على الاستخدام الصفي

في العرض الصفّي، تساعد الهوية المحيطة على منح شاشة P2 شخصية عربية متماسكة من دون إضافة زخارف واضحة. وبما أن النقوش تنخفض خلف البطاقات وتظهر أكثر في الجوانب، يبقى المسار الإدراكي الأساسي واضحاً: يقرأ المعلم شارة الصوت، يحدد البطاقة النشطة، ثم يوجه الطلاب إلى الترديد الجماعي.

هذا التوزيع لا يضيف معلومات جديدة ولا يغير الإيقاع التعليمي؛ إنما يحسن إحساس البيئة البصرية حول المحتوى. لذلك تظل فلسفة **الصوت أولاً** محفوظة، ولا يتحول النمط العربي إلى خلفية مزاحمة.

## الاختبار

تم اختبار P2 في الوضعين النهاري والليلي، مع فحص الحالة النشطة لصوت `/ب/` بصرياً. كما أُعيد تشغيل اختبار الثبات متعدد الدقات، وتحققت النتائج التالية:

| الدقة | الوضع | التمرير الأفقي | التمرير الرأسي | النتيجة |
|---|---|---:|---:|---|
| 1280×720 | Light / Dark | لا | لا | ناجح |
| 1366×768 | Light / Dark | لا | لا | ناجح |
| 1440×900 | Light / Dark | لا | لا | ناجح |
| 1920×1080 | Light / Dark | لا | لا | ناجح |

تطابقت قيمة `scrollHeight` مع `clientHeight` في الحالات المختبرة، ولم تتغير أبعاد منطقة P2 أو مواضع البطاقات بسبب طبقة الخلفية.
