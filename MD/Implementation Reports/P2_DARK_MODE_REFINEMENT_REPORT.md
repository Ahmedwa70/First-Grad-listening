# P2 Dark Mode Refinement Report

## Scope

تم تنفيذ هذا التحديث على مرحلة **P2 — الصوت أولاً** بهدف تحسين وضوح التسلسل التعليمي في وضع العرض الليلي: **الصوت الحالي ← البطاقة المختارة ← الترديد الجماعي**. اقتصر التعديل على نص التوجيه العلوي وعلى طبقة CSS خاصة بالوضع الليلي لبطاقات الأصوات وشارة التركيز الصوتي.

لم يتم تغيير بنية HTML، أو بيانات الدرس، أو إدارة الحالة، أو منطق تشغيل الصوت، أو آلية الترديد الجماعي، أو ترتيب مراحل التعلم.

## التغييرات المنفذة

| المجال | التغيير | القيمة الصفية |
|---|---|---|
| **شريط التوجيه العلوي** | استُبدلت الصياغة الطويلة بالنص الديناميكي: `صوت {اسم الحرف} · اضغط «ردّد معي» للترديد الجماعي · [ ␣ ] لإعادة الصوت`. | يقرأ المعلم التعليمات بسرعة، ويظهر الفعل التالي بوضوح من دون شرطات أو أعمدة بصرية حادة. |
| **اتجاه الشريط** | ضُبط `direction: rtl` و`unicode-bidi: plaintext` على شريط التوجيه. | يحافظ على ترتيب النص العربي ورمز `[ ␣ ]` بصورة مستقرة. |
| **البطاقات غير النشطة** | أضيف سطح داكن أزرق-بترولي متدرج، وحدود فاتحة منخفضة الشدة، وظل داخلي هادئ. | يمنع تحول البطاقات إلى رمادي ميت، ويحافظ على قابلية تمييز البطاقات الأربع على البروجيكتور. |
| **الفونيمات** | رُفعت إضاءة الفونيم العربي في الوضع الليلي مع ظل نصي محدود، بينما بقي اسم الحرف ثانوياً. | يبقى الصوت المكتوب هو العنصر الأوضح، بما ينسجم مع مبدأ الصوت أولاً. |
| **البطاقة النشطة** | أضيفت خلفية مختلفة وحدود وGlow هادئ خاص بكل لون: تركواز، أخضر، بنفسجي، وذهبي. | يستطيع المعلم تحديد الصوت الجاري فوراً من دون تأثير Gaming أو وهج زائد. |
| **شارة الصوت العلوية** | عُزز سطح شارة الصوت وحدّها وظلها الداخلي بصورة محدودة. | تبقى الشارة مرساة التركيز الأولى، مع بقاء البطاقة النشطة مرساة التركيز الثانية. |

## الهوية اللونية في الوضع الليلي

حافظت المعالجة على الترميز الثابت للمشروع، مع رفع الإضاءة بدلاً من تغيير الألوان الأساسية:

| الصوت | اللون المستخدم في الحالة النشطة |
|---|---|
| `/ب/` | تركواز فاتح مع حد تركوازي واضح |
| `/ت/` | أخضر فاتح مع حد أخضر واضح |
| `/ث/` | بنفسجي فاتح مع حد بنفسجي واضح |
| `/ن/` | ذهبي فاتح مع حد ذهبي واضح |

تم تجنب الخلفيات البيضاء الشفافة القديمة في الوضع الليلي، واستُبدلت بأسطح داكنة ذات فرق لوني واضح بين الحالة العادية والحالة النشطة. كما بقي اسم الحرف أقل وزناً من الفونيم، حتى لا ينافس الهدف الصوتي.

## اختبار الدقات والوضع الليلي

أُعيد تشغيل اختبار P2 متعدد الدقات بعد التعديل. شمل الاختبار الحالة الابتدائية والحالة النشطة، وفحص التمرير الأفقي والرأسي، وتساوي `scrollHeight` و`clientHeight` داخل منطقة P2.

| الدقة | التمرير الأفقي | التمرير الرأسي | P2 بدون تمرير | النتيجة |
|---|---:|---:|---:|---|
| 1280×720 | لا | لا | نعم | ناجح |
| 1366×768 | لا | لا | نعم | ناجح |
| 1440×900 | لا | لا | نعم | ناجح |
| 1920×1080 | لا | لا | نعم | ناجح |

كما تم فحص الوضع الليلي بصرياً في الحالة النشطة لصوت `/ب/`. أظهر الفحص أن البطاقة النشطة تستخدم سطحاً تركوازياً داكناً وحداً تركوازياً واضحاً، في حين تستخدم البطاقات غير النشطة سطحاً داكناً موحداً وحدوداً أخف. وبذلك بقي الفرق بين الحالتين واضحاً من دون رفع شدة الظلال إلى مستوى مشتت.
