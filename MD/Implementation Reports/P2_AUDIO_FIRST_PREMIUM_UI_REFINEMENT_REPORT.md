## التغييرات البصرية المنفذة

### 1. أولوية الاستماع والصوت

أصبح المسرح العلوي مدمجاً وصغيراً نسبياً، بينما بقيت بطاقات الفونيمات الأربع هي العنصر الأكبر في الشاشة. الفونيم داخل البطاقة أكبر وأثقل بصرياً، في حين خُفّض وزن اسم الحرف ليبقى مرجعاً هادئاً ولا ينافس الصوت.

في الحالة الابتدائية تظهر فقط رسالة **«اختر صوتاً»** وبطاقات الفونيمات. تُخفى أيقونة التشغيل، زر الترديد، دليل الأصابع، وزر الانتقال إلى أن يختار المعلم صوتاً.

### 2. كشف تدريجي متوافق مع منطق P2 الحالي

استُخدمت حالة الاختيار الموجودة مسبقاً (`.sound-btn.active`) كمفتاح CSS للكشف التدريجي، دون لمس JavaScript:

| الحالة | ما يراه الصف | ما يتاح للمعلم |
|---|---|---|
| **1 — الاستماع** | اختيار صوت وبطاقات الفونيمات فقط. | تلميح هادئ «استمع ثم اختر الصوت». |
| **2 — بعد اختيار الصوت / الترديد** | الفونيم النشط وأيقونة صوت صغيرة مرتبطة به. | زر «ردّد معي» هو الإجراء الأبرز، مع مرجع الأصابع والانتقال بأوزان أخف. |
| **3 — عدّ الأصابع** | لا تتغير بنية الصفحة أو تدفقها. | دليل الأصابع ظاهر كمرجع معلم منخفض التباين عند الحاجة. |

لا توجد حالة JavaScript مستقلة لتمييز «عدّ الأصابع» حالياً، وبناءً على القيد الصريح بعدم تعديل المنطق، لم يُفترض أو يُنشأ انتقال تلقائي وهمي. بدلاً من ذلك، يبقى دليل الأصابع مخفياً قبل اختيار الصوت، ثم يظهر كمرجع للمعلم بعد تفعيل مسار الصوت.

### 3. شريط أدوات المعلم

أعيد توزيع الوزن البصري في الجزء السفلي. أصبح زر **«ردّد معي»** هو العنصر الأكثر ظهوراً؛ أما دليل الأصابع وزر الانتقال إلى P3 فهما أهدأ بصرياً. أضيفت علامات تسلسلية دقيقة للمعلم: `①` للاستماع، و`②` بعد اختيار صوت، و`③` لدليل الأصابع. لا تُنشئ هذه العلامات مهمة جديدة للطالب ولا تستبدل توجيه المعلم.

### 4. الهوية والحركة

حافظت الواجهة على RTL، متغيرات الألوان القائمة، وألوان الحروف الثابتة. استُخدمت ظلال خفيفة وحدود هادئة فقط. لا توجد حركة دخول أو تلقائية جديدة؛ بقيت الاستجابات الحركية قصيرة ومرتبطة بالفعل الذي يقوم به المعلم. كما أضيف دعم `prefers-reduced-motion` لتعطيل الحركة عند الحاجة.

## الحفاظ على الفلسفة التعليمية

| المبدأ | كيفية المحافظة عليه |
|---|---|
| **الصوت قبل الشكل** | لم يُكشف شكل حرف مستقل، وبقي الفونيم لا الاسم هو المحتوى البصري الأقوى. |
| **المعلم هو المتحكم** | لم يتغير `goToPhase` أو `p2SelectLetter` أو `p2PlaySound` أو `p2ToggleChoral`. |
| **طلاب صينيون A0** | خُفّضت النصوص الثانوية وأخفيت الأدوات غير اللازمة في بداية النشاط لتقليل الحمل المعرفي. |
| **الكشف التدريجي** | لا تظهر أدوات المعلم السفلية قبل اختيار صوت. |
| **Projector-first** | بقيت بطاقات الفونيم كبيرة وواضحة، مع اختبار دقات عرض صفية ومكتبية شائعة. |
| **لا Auto-play** | لم تُضف أي آلية تشغيل تلقائي أو مؤقت تعليمي. |

## المخاطر التربوية التي تم تجنبها

لم تُضف زخارف أو عناصر لعب، ولم تُحوّل الواجهة إلى تطبيق استخدام فردي. كذلك لم يُعرض دليل الأصابع أو زر الانتقال في اللحظة الأولى، مما يمنع مزاحمة مهمة الاستماع. ولم يُصعّر الفونيم من أجل النصوص المساعدة، لأن الفونيم هو المحتوى الذي يجب أن يراه الطالب من بعيد.

## التحقق الوظيفي والبصري

### فحص الحالة والتفاعل

| الاختبار | النتيجة |
|---|---|
| دخول P2 | أزرار الترديد، دليل الأصابع، والانتقال مخفية؛ لا يوجد تمرير داخل P2. |
| اختيار /ب/ أو /ث/ | يظهر الفونيم وأيقونة التشغيل وأدوات المعلم؛ تبقى الحاوية مستقرة بلا تغير ارتفاع. |
| تشغيل الصوت | بقي مسار `p2SelectLetter()` و`p2PlaySound()` قائماً كما هو. |
| زر الترديد | بقي الزر متصلاً بـ`p2ToggleChoral()` كما هو. |
| الانتقال إلى P3 | بقيت دالة `goToPhase(2)` في HTML دون تعديل. |

## النتيجة

P2 أصبحت واجهة صوتية صفية أكثر هدوءاً ووضوحاً: تبدأ بالاستماع، تكشف أدوات الترديد بعد اختيار الصوت، وتحافظ على دليل الأصابع والانتقال كدعم للمعلم لا كمنافس للمهمة التعليمية الأساسية. تم ذلك بالكامل دون تعديل المحرك التعليمي أو بيانات الدرس أو تدفق المرحلة.
