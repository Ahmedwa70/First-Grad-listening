## التغييرات البصرية المنفذة

| العنصر | التعديل المنفذ |
|---|---|
| شارة المرحلة | ضبطت كـBadge صغيرة هادئة مع مساحة علوية واضحة ولا تنافس عنوان الدرس. |
| بطاقة التعلم | خُفض ارتفاعها إلى **288px** في بيئة الاختبار، مع سطح أبيض هادئ وحد ذهبي رقيق وعمق بصري خفيف. |
| عنوان الدرس والوصف | أصبح العنوان العربي واضحاً وموزوناً، وتحته الصينية الداعمة، ثم فاصل ذهبي رفيع ووصف: **تعلم أول 4 حروف عربية**. |
| الحروف المستهدفة | بقيت الحروف الحقيقية للدرس **ب، ت، ث، ن** داخل أربع بطاقات متساوية وملونة بهوية ناعمة. لم يُضف حرف جديد حفاظاً على محتوى الدرس وSchema الحاليين. |
| زر البدء | أصبح بارتفاع **70px** ويعرض فقط `▶ ابدأ الدرس` مع شارة الاختصار `[Space]`، وأزيلت الصينية من داخله. |
| النص السفلي | أعيد عرضه كسطرين هادئين: **العربية للناطقين بالصينية** ثم **المستوى A0**، مع خطين ذهبيين رقيقين على الجانبين. |
| الحركة | لا توجد حركة للعناصر الأساسية؛ تفاعل hover للزر خفيف جداً (`translateY(-1px)`) فقط. |

## التحقق

| الاختبار | النتيجة |
|---|---|
| عرض سطح المكتب 16:9 | البطاقة متوازنة في المركز، والنص والحروف والزر واضحة بصرياً. |
| التمرير | تحققت مساواة `scrollHeight` و`clientHeight` لحاوية P1 ومنطقة المحتوى. |
| منطق البدء | زر البدء لا يزال يستدعي `advanceP1()`. |
| الحالة الابتدائية | بقيت `data-step="0"`. |
| المحتوى التعليمي | بقي تسلسل الحروف `بتثن` كما هو. |
| المشهد التالي | عنصر `.p1-stage-alphabet-scene` موجود. |

## خلاصة الجودة

حققت P1 الآن تسلسلاً بصرياً مباشراً وواضحاً: **شارة المرحلة → عنوان الدرس → هدف تعليمي قصير → الحروف → زر البدء → مستوى الدرس**. تم ذلك من دون تغيير أي وظيفة أو منطق أو محتوى تعلمي، وبصورة مناسبة للبروجكتور ولطالب صيني مبتدئ.
