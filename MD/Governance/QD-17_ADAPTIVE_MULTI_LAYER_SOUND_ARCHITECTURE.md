## 2. Problem Statement — بيان المشكلة

### 2.1 الوضع الحالي: طبقات متفرقة بلا نظام

المشروع يحتوي حالياً عناصر صوتية متعددة لكنها نشأت بقرارات منفصلة:

| العنصر | القرار | الحالة | التنسيق مع الأخرى |
|--------|--------|-------|-------------------|
| Audio (MP3 + Web Speech) | QD-05, QD-06 | ✅ مبني | مستقل |
| Sound Identity (`/ب/`) | QD-16 | ✅ مبني | مستقل |
| Arabic Letter (`ب`) | أصلي | ✅ مبني | مستقل |
| IPA Reference (`b`) | أصلي | ✅ مبني | مستقل |
| L1 Bridge (`吧`) | أصلي | ✅ مبني | مستقل |
| Articulation (SVG) | QD-17 Articulation | ❌ مقترح | مستقل |

**المشكلة**: كل عنصر صُمم بمعزل. لا يوجد نظام يحدد:
- **متى** تظهر كل طبقة
- **لمن** تظهر
- **كيف** تتفاعل مع الأخرى
- **لماذا** تظهر في هذا السياق

### 2.2 السؤال المركزي

> هل يجب عرض كل الطبقات دائماً أمام الطالب؟ أم أن أفضل تجربة تعليمية تعتمد على كشف تدريجي تكيفي حسب المرحلة والنشاط وصعوبة الصوت؟

### 2.3 الإجابة: النظام التكيفي

عرض كل الطبقات دائماً **خطأ تربوي**. الأدلة:

1. **نظرية الحمل المعرفي (Sweller)**: كل طبقة إضافية = حمل خارجي. عرض IPA + L1 + Articulation معاً في P2 يُغرق المبتدئ.
2. **Doc 05 صريحة**: IPA = "سياق داعم" بنسبة 60% — ليست أولية.
3. **Doc 07 صريحة**: P2 = "أيقونات الصوت نشطة. لا عنصر آخر مرئي" — الصوت فقط.
4. **مبدأ الكشف التدريجي** (DESIGN_PHILOSOPHY §5): لا يُعرض كل شيء دفعة واحدة.
5. **الممارسة التعليمية**: المعلم الماهر يُدخل المعلومة حين يحتاجها الطالب — لا قبلها.

## 4. Proposed Architecture — المعمارية المقترحة

### 4.1 التعريف

**Adaptive Multi-Layer Sound Architecture (AMLSA)** هو نظام تمثيل صوتي متعدد الطبقات يتكيف مع:
- المرحلة التعليمية (P1–P7)
- نوع النشاط (استماع، تمييز، إنتاج)
- صعوبة الصوت (حاسم، مهم، اختياري)
- هدف المعلم (تعريف، تصحيح، تقييم)

### 4.2 مخطط المعمارية

```
┌──────────────────────────────────────────────────────────────┐
│           ADAPTIVE MULTI-LAYER SOUND ARCHITECTURE            │
│                        (AMLSA v1.0)                          │
│                                                               │
│  ┌──────────────────────────────────────────────────────┐    │
│  │ CORE LAYERS — موجودة دائماً في البيانات              │    │
│  │                                                       │    │
│  │  L1: Audio Layer          — الصوت المسموع            │    │
│  │  L2: Sound Identity       — /ب/ (الرمز الأولي)       │    │
│  │  L3: Arabic Letter        — ب (الشكل المكتوب)        │    │
│  │  L4: Color Identity       — #0E7C7B (اللون الثابت)   │    │
│  └──────────────────────────────────────────────────────┘    │
│                                                               │
│  ┌──────────────────────────────────────────────────────┐    │
│  │ ADAPTIVE LAYERS — تظهر حسب السياق                    │    │
│  │                                                       │    │
│  │  L5: Articulation         — SVG حركة النطق           │    │
│  │  L6: IPA Reference        — θ (مرجع أكاديمي)        │    │
│  │  L7: L1 Bridge            — 吧 (تقريب باللغة الأم)   │    │
│  │  L8: Discrimination Aid   — مقارنة بصرية بين صوتين   │    │
│  └──────────────────────────────────────────────────────┘    │
│                                                               │
│  ┌──────────────────────────────────────────────────────┐    │
│  │ CONTROL LAYER — تحكم المعلم                          │    │
│  │                                                       │    │
│  │  Visibility Rules: أي طبقة مرئية في أي سياق          │    │
│  │  Teacher Override: المعلم يستطيع إظهار/إخفاء أي طبقة │    │
│  │  Progressive Reveal: الكشف التدريجي بـ Space          │    │
│  └──────────────────────────────────────────────────────┘    │
│                                                               │
└──────────────────────────────────────────────────────────────┘
```

## 5. Layer Definitions — تعريف الطبقات

### L1: Audio Layer — طبقة الصوت

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | تشغيل الصوت العربي — القناة الحسية الأولى |
| **السؤال الذي تجيبه** | "كيف يبدو هذا الصوت؟" |
| **البيانات** | `audioFile`, `slowAudio` (مستقبلاً) |
| **المحرك** | `AudioManager` (MP3 + Web Speech fallback) |
| **الرؤية** | ✅ **Always Active** — في كل مرحلة فيها صوت |
| **لمن** | الطالب (سماعياً) + المعلم (تحكم) |
| **أنماط فرعية** | Normal speed (tha.mp3), Slow speed (p2_phoneme_th_slow.mp3 — مستقبلاً) |

### L2: Sound Identity Layer — طبقة هوية الصوت

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | الرمز البصري الأولي للصوت — أول ما يراه الطالب |
| **السؤال الذي تجيبه** | "ما رمز هذا الصوت؟" |
| **البيانات** | `phoneme: '/ب/'` (QD-16 — عربي لا IPA) |
| **الرؤية** | ✅ **Always Active** — في P2 إلى P7 |
| **لمن** | الطالب + المعلم |
| **المبرر** | QD-16: الحرف العربي بين شرطتين يُصفّر تداخل البينيين ويتوافق مع Doc 04 |

### L3: Arabic Letter Layer — طبقة الحرف العربي

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | الشكل المكتوب للحرف — ربط الصوت بالكتابة |
| **السؤال الذي تجيبه** | "كيف يُكتب هذا الصوت؟" |
| **البيانات** | `char: 'ب'`, `name: 'باء'`, `dots`, `dotPosition`, `fact` |
| **الرؤية** | ✅ **Active from P3** — لا تظهر في P2 (الصوت يسبق الحرف) |
| **لمن** | الطالب + المعلم |
| **المبرر** | "الصوت قبل الحرف — دائماً" (Doc 01) |

### L4: Color Identity Layer — طبقة اللون

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | ترميز لوني ثابت لكل حرف عبر كل المراحل |
| **السؤال الذي تجيبه** | "أي حرف هذا؟" (تمييز فوري بدون قراءة) |
| **البيانات** | `color: '#0E7C7B'` + CSS `--color-ba` |
| **الرؤية** | ✅ **Always Active** — من P1 إلى P7 |
| **لمن** | الطالب + المعلم |
| **المبرر** | DESIGN_PHILOSOPHY §4: ترميز لوني ثابت |

### L5: Articulation Layer — طبقة التصوير النطقي

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | تمثيل بصري لكيفية إنتاج الصوت جسدياً |
| **السؤال الذي تجيبه** | "كيف أُنتج هذا الصوت بفمي؟" |
| **البيانات** | `articulation: { place, manner, voicing, template, steps, description }` |
| **التقنية** | Hybrid SVG + CSS Animation (QD-17 Articulation) |
| **الرؤية** | 🔄 **Adaptive** — تظهر حسب السياق |
| **لمن** | الطالب (عبر البروجكتور) + المعلم (تحكم) |
| **متى تظهر** | P2 (ن-04 تصحيح)، P3 (اختياري)، P6 (مقارنة عند خطأ) |
| **المبرر** | Doc 07: `mouth_th_1/2/3.svg` + "رسوم متحركة للفم" |

### L6: IPA Reference Layer — طبقة المرجع الصوتي الدولي

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | مرجع أكاديمي للمتعلمين الذين يعرفون IPA |
| **السؤال الذي تجيبه** | "ما الرمز الأكاديمي الدولي لهذا الصوت؟" |
| **البيانات** | `ipa: 'θ'` |
| **الرؤية** | 🔄 **Adaptive** — P3 فقط كشارة صغيرة |
| **لمن** | متعلم متقدم أو معلم يريد المرجع |
| **المبرر** | Doc 05: "سياق داعم"، Doc 06: "اختياري" |
| **ملاحظة** | ليست طبقة أولية — لا تظهر في P2 |

### L7: L1 Bridge Layer — طبقة الجسر اللغوي

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | تقريب الصوت بلغة الأم (صيني حالياً) |
| **السؤال الذي تجيبه** | "ما الأقرب لهذا الصوت في لغتي؟" |
| **البيانات** | `chinesePinyin: '吧 (bā)'` (مستقبلاً: كائن متعدد اللغات) |
| **الرؤية** | 🔄 **Adaptive** — P3 فقط |
| **لمن** | الطالب الصيني (حالياً) — مستقبلاً حسب اللغة |
| **المبرر** | تقريب مفيد لبعض الأصوات، لكن مضلل لأخرى (ث لا مقابل) |
| **قيد** | لا تظهر للأصوات التي لا مقابل لها — "لا مقابل" نفسها معلومة مفيدة |

### L8: Discrimination Aid Layer — طبقة دعم التمييز

| الحقل | القيمة |
|-------|--------|
| **الوظيفة** | مقارنة بصرية بين صوتين متشابهين |
| **السؤال الذي تجيبه** | "ما الفرق بين هذين الصوتين؟" |
| **البيانات** | مُشتقة من L3 + L5 (مقارنة حروف + مقارنة Articulation) |
| **الرؤية** | 🔄 **Adaptive** — P6 فقط عند الحاجة |
| **لمن** | الطالب + المعلم |
| **المبرر** | التمييز بين ت/ث أو ص/س يحتاج أكثر من الصوت — يحتاج مقارنة بصرية |
| **ملاحظة** | **طبقة جديدة** — غير موجودة في النظام الحالي |

## 6. Adaptive Rules — قواعد التكيف

### 6.1 المبدأ الأساسي

```
الطبقة تظهر حين يحتاجها الطالب — لا قبلها ولا بعدها.
المعلم يستطيع تجاوز أي قاعدة (Teacher Override).
```

### 6.2 مصفوفة الرؤية: المراحل × الطبقات

| الطبقة | P1 | P2 | P3 | P4 | P5 | P6 | P7 |
|--------|----|----|----|----|----|----|----| 
| **L1: Audio** | — | ✅ | ✅ | ✅ | ✅ | ✅ | ⚪ |
| **L2: Sound Identity** | — | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **L3: Arabic Letter** | — | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **L4: Color** | ⚪ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **L5: Articulation** | — | 🔶 | 🔶 | — | — | 🔶 | — |
| **L6: IPA** | — | ❌ | 🔶 | — | — | — | — |
| **L7: L1 Bridge** | — | ❌ | 🔶 | — | — | — | — |
| **L8: Discrimination** | — | — | — | — | — | 🔶 | — |

**المفتاح**: ✅ = دائماً | ❌ = ممنوع | 🔶 = حسب السياق | ⚪ = ثانوي | — = غير ذي صلة

### 6.3 قواعد التكيف التفصيلية

#### القاعدة 1: P2 — اكتساب الصوت

```
الطبقات النشطة:   L1 (Audio) + L2 (Sound Identity) + L4 (Color)
الطبقات المخفية:  L3 (Letter) + L6 (IPA) + L7 (L1 Bridge)
الطبقات الشرطية:  L5 (Articulation) — فقط في نشاط ن-04 (تصحيح الثاء)
```

**المبرر**: "الصوت قبل الحرف". الطالب يسمع ويميّز — لا يقرأ.

**ن-04 (التصحيح الصوتي)**: L5 تنشط لأن الطالب يحتاج توجيهاً حركياً لإنتاج صوت غائب عن L1.

#### القاعدة 2: P3 — ربط الصوت بالحرف

```
الطبقات النشطة:   L1 + L2 + L3 + L4
الطبقات الشرطية:  L5 (زر "كيف يُنطق؟")
                   L6 (IPA badge — 60% حجم — اختياري)
                   L7 (L1 Bridge — تحت البطاقة — اختياري)
```

**المبرر**: P3 هي نقطة الربط بين الصوت والحرف. الطبقات الشرطية تُضاف كسياق داعم — لا تنافس المحتوى الأساسي.

**ترتيب الكشف التدريجي**: char → dots → phoneme → fact → [IPA] → [L1 Bridge]

#### القاعدة 3: P6 — التمييز السمعي

```
الطبقات النشطة:   L1 + L2 + L3 + L4
الطبقات الشرطية:  L5 (مقارنة Articulation عند خلط ت/ث)
                   L8 (Discrimination Aid — مقارنة جنباً إلى جنب)
```

**المبرر**: التمييز يبدأ سمعياً. المقارنة البصرية (L5 + L8) تُعرض فقط عند صعوبة التمييز.

#### القاعدة 4: الصعوبة تحدد الطبقات

| فئة الصوت | أمثلة | الطبقات الموصى بها |
|-----------|-------|-------------------|
| **حاسم** (غائب عن L1) | ع، ح، خ، غ، ث، ذ، ظ، ص، ض، ط، ق | L1 + L2 + L3 + L4 + **L5** + L8 |
| **مهم** (مختلف عن L1) | ر، هـ، ء | L1 + L2 + L3 + L4 + L5 (اختياري) |
| **اختياري** (مشابه لـ L1) | ب، ت، ن، م، ل، س، ز، ش، ف، ك، ج، ي، د، و | L1 + L2 + L3 + L4 |

**المبدأ**: كلما كان الصوت أصعب، زادت الطبقات النشطة. الأصوات السهلة لا تحتاج Articulation.

#### القاعدة 5: Teacher Override

```
المعلم يستطيع في أي لحظة:
- إظهار طبقة مخفية (مثلاً: عرض Articulation لحرف "سهل" لطالب يعاني)
- إخفاء طبقة ظاهرة (مثلاً: إخفاء L1 Bridge لتحدي الطلاب)
- تكرار أي طبقة بأي ترتيب
```

**الآلية**: اختصارات لوحة المفاتيح أو أزرار في Teacher HUD (تصميم مستقبلي).

## 7. Cross-Phase Usage — الاستخدام عبر المراحل

### 7.1 P2 — الصوت أولاً

```
[ن-01: استماع صامت]
    الطبقات: L1 فقط (صوت)
    الهدف: الطالب يسمع بدون أي مشتتات بصرية

[ن-02: ترديد جماعي]
    الطبقات: L1 + L2 (صوت + هوية الصوت) + L4 (لون)
    الهدف: الطالب يسمع ويردد — يرى الرمز ويربطه بالصوت

[ن-03: عد الأصابع]
    الطبقات: L1 + L2 + L4
    الهدف: ربط حركي — عدد الأصابع = الصوت

[ن-04: تصحيح الثاء]
    الطبقات: L1 + L2 + L4 + *** L5 (Articulation) ***
    الهدف: توجيه حركي لإنتاج صوت غائب
    التسلسل: صورة اللسان → صوت بطيء → ترديد → صوت طبيعي
```

### 7.2 P3 — ربط الصوت بالحرف

```
[لكل حرف — كشف تدريجي]
    الخطوة 1: L3 (الحرف) + L4 (اللون)
    الخطوة 2: L3 + dots (النقاط)
    الخطوة 3: L1 + L2 (الصوت + الهوية)
    الخطوة 4: fact (القاعدة)
    اختياري: L6 (IPA badge) + L7 (L1 Bridge)
    اختياري: L5 (زر "كيف يُنطق؟")
```

### 7.3 P6 — التمييز السمعي

```
[D1: تعرّف — أي حرف سمعت؟]
    الطبقات: L1 (صوت) → L2 + L3 + L4 (كشف الإجابة)

[D2: نفس أم مختلف؟]
    الطبقات: L1 (صوتان) → L2 + L3 + L4 (كشف)
    شرطي: L8 (مقارنة) عند خلط ت/ث

[D3: أصوات متقاربة]
    الطبقات: L1 (صوت) → L2 + L3 + L4 (كشف)
    شرطي: L5 + L8 (مقارنة Articulation) عند فشل التمييز
```

## 10. Considered Alternatives — البدائل المدروسة

### Alternative A: نظام ثابت لكل الأصوات

كل الطبقات مرئية دائماً في كل مرحلة.

| الجانب | التقييم |
|--------|---------|
| البساطة | ✅ لا منطق تكيف |
| الحمل المعرفي | ❌ كارثي — 6+ طبقات بصرية في P2 |
| التوافق مع الوثائق | ❌ Doc 07: "لا عنصر آخر مرئي" في P2 |
| التجربة التعليمية | ❌ إغراق المبتدئ |

**مرفوض**: يتعارض مع الكشف التدريجي ومع Doc 07 صراحة.

### Alternative B: IPA محور النظام

IPA هو التمثيل الأولي في كل المراحل.

| الجانب | التقييم |
|--------|---------|
| المعيارية الدولية | ✅ نظام عالمي |
| الطالب الصيني | ❌ تداخل بينيين كارثي (QD-16) |
| التوسع | ⚠️ يعمل مع لغويين، يفشل مع مبتدئين |
| التوافق مع الوثائق | ❌ كل الوثائق: IPA "اختياري/داعم" |

**مرفوض**: QD-16 أثبت أن IPA كتمثيل أولي ضار بالطالب الصيني. الوثائق صريحة: IPA = داعم لا أولي.

### Alternative C: الصوت فقط (بلا تمثيل بصري)

حذف كل الطبقات البصرية — الصوت فقط.

| الجانب | التقييم |
|--------|---------|
| النقاء السمعي | ✅ لا مشتتات |
| التطبيق | ❌ مستحيل — المعلم يحتاج مرجعاً بصرياً |
| الذاكرة | ❌ قناة حسية واحدة = ذاكرة أضعف |
| التوافق | ❌ المشروع يعتمد "استجابة حسية متعددة" |

**مرفوض**: يتعارض مع مبدأ الاستجابة الحسية المتعددة.

### Alternative D: Adaptive Multi-Layer (هذا القرار)

**مقبول**: يجمع بين كل البدائل بشكل تكيفي. كل بديل يصبح صحيحاً في سياقه:
- P2 ن-01 = "الصوت فقط" (Alternative C)
- P3 = كل الطبقات مع كشف تدريجي (Alternative A المعدّل)
- L2 = عربي لا IPA (رفض Alternative B)

### Alternative E: نظام مبني على AI/التعلم الآلي

نظام يتكيف تلقائياً مع أداء كل طالب.

| الجانب | التقييم |
|--------|---------|
| التخصيص | ✅ أعلى مستوى |
| Offline | ❌ يحتاج خادم أو نموذج محلي |
| Teacher-controlled | ❌ يُقلل سيطرة المعلم |
| التعقيد | ❌ مستوى هندسي مختلف تماماً |

**مرفوض**: يتعارض مع Offline-first وTeacher-controlled. ممكن مستقبلاً (v3.0+).

## 11. Final Decision — القرار النهائي

### 11.1 القرار

**اعتماد Adaptive Multi-Layer Sound Architecture (AMLSA v1.0)** كمعمارية تأسيسية لتمثيل وتعليم الأصوات العربية في المنصة.

### 11.2 المبررات

| البُعد | المبرر |
|--------|--------|
| **تربوي** | الكشف التدريجي + تكيف مع صعوبة الصوت = أفضل تجربة تعلم |
| **معرفي** | الحمل المعرفي مُدار — الطبقات تظهر حين يحتاجها الطالب |
| **تقني** | يبني على البنية الموجودة (DATA→ENGINE→VIEW) بلا إعادة هيكلة |
| **توسع دولي** | الطبقات الأساسية عالمية (Audio, Letter, Color)، الطبقات التكيفية تتخصص حسب اللغة |
| **توافق مع الوثائق** | يُطبق كل الوثائق: Doc 07 (Articulation)، Doc 05 (IPA اختياري)، Doc 04 (تصحيح الثاء) |

### 11.3 ما يتغير عملياً

| الآن | بعد الاعتماد |
|------|-------------|
| طبقات بدون تنسيق | 8 طبقات مُعرّفة بوظيفة ورؤية واضحة |
| كل الطبقات ظاهرة في P3 | P3 تكشف تدريجياً حسب القواعد |
| لا Articulation | L5 مُصمم وجاهز للتنفيذ (QD-17 Articulation) |
| لا Discrimination Aid | L8 مُعرّفة للتنفيذ المستقبلي |
| IPA بدون تصنيف واضح | L6 = مرجع داعم في P3 فقط |

## 12. Independent Expert Recommendation — رأي الخبير المستقل

### لو بنيت منصة عربية عالمية من الصفر:

**سأختار: D — Adaptive Multi-Layer Sound Architecture**

**السبب التربوي**: تعليم الأصوات ليس مسألة "عرض" بل مسألة "بناء تمثيل عقلي". التمثيل العقلي يُبنى بطبقات — سمعية ثم حركية ثم بصرية ثم رمزية. عرض كل الطبقات معاً يُربك. إخفاؤها كلها يُبطئ. التكيف هو الحل الوحيد الذي يحترم مسار البناء العقلي.

**السبب المعرفي**: نظرية الترميز المزدوج (Paivio) تقول إن المعلومة المُخزّنة في قناتين حسيتين (سمعية + بصرية) تُسترجع بضعف الاحتمال. لكن 6 قنوات معاً = فوضى. الحل: قناتان في كل لحظة، تتبدلان حسب المرحلة.

**السبب التقني**: AMLSA لا يحتاج إعادة هيكلة. البيانات موجودة في lesson-01.js. المحرك (app.js) يعرض `letter.phoneme` / `letter.ipa` بالفعل. المطلوب: إضافة حقل `articulation` + دوال عرض + CSS + قواعد رؤية. كل هذا يتوافق مع DATA→ENGINE→VIEW.

**السبب الدولي**: الطبقات الأساسية (Audio, Letter, Color) لا تتغير حسب اللغة. الطبقات التكيفية (L1 Bridge, Articulation descriptions) تتخصص. هذا يعني: 80% من النظام عالمي، 20% يتكيف. أفضل نسبة ممكنة.

**تحذير واحد**: لا تبنِ محرك تكيف معقد في v1. ابدأ بمصفوفة رؤية ثابتة (القسم 6.2). التكيف الديناميكي (حسب أداء الطالب) يأتي في v3.0+ حين تتوفر بيانات أداء فعلية.
