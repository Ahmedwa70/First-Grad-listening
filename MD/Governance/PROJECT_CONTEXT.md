# PROJECT_CONTEXT.md — سياق المشروع

> ذاكرة دائمة لوكلاء AI. الهدف: أي وكيل يقرأ هذا المجلد يفهم المشروع فوراً دون الحاجة لإعادة البحث.

## ما هو المشروع؟

درس تفاعلي HTML واحد (صفحة تُعرض عبر بروجكتور) لمحاضرة عربية أولى بمستوى A0
لمتحدثي الصينية (طلاب جامعيون 18–22). يقدم 4 حروف عربية: **ب ت ث ن**.
الدرس موجّه بالكامل للمعلم (Teacher-Controlled) — لا يوجد تشغيل تلقائي؛ كل إجراء من المعلم
عبر لوحة المفاتيح أو الأزرار.

## الفئة المستهدفة وبيئة التشغيل

- طلاب صينيون مبتدئون تماماً (A0) لا يعرفون العربية.
- بيئة الفصل: بروجكتور + شاشة كبيرة، تحكم حقيقي (لوحة مفاتيح) بيد المعلم.
- **Offline كامل**: لا Google Fonts، لا CDN — كل شيء محلي (خطوط woff2/ttf في assets/fonts).
- الصوت: MP3 محلي مع نسخة احتياطية Web Speech API (ar-SA).

## المصدر المرجعي

- `Work plan\` هو مصدر الحقيقة (فلسفة، مناهج، تصميم، معمارية، تنفيذ).
- `Work plan\البرومبت.txt` — التعليمات الأصلية لتوليد المحاضرة.
- `Work plan\الاهداف الان.txt` — أهداف الفصل الحالية.
- `Work plan\انشطة يجب اضافتها.txt` — نشاطات مطلوب إضافتها (لم تُنفَّذ جميعها بعد).
- `Work plan\before-order.txt` — تسلسل عمل وكلاء AI وهيكل الذاكرة المطلوب.

## المبادئ الثابتة

1. المحاضرة تعتمد "الصوت أولاً" (P2 قبل رؤية شكل الحرف).
2. الفصل بين البيانات والعرض: `lesson-01.js` بيانات خالصة ومجمّدة، و`app.js`/CSS مسؤولة عن العرض.
3. المعلم هو المتحكم الوحيد — أي تغيير يجب ألا يكسر التحكم بلوحة المفاتيح.
4. التصميم موجّه للبروجكتور (أحجام خطوط ضخمة، ألوان متباينة، RTL كامل).
