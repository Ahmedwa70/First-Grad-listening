# أدوات التحقق البصري (Visual QA)

لقطات شاشة **متعددة المقاسات** لصفحات المشروع مع **فحوص عددية** تكشف الاقتطاع
والتراكب والتجاوز — بلا أي اعتماديات خارجية، وبلا كتابة خارج مجلد المشروع.

## التشغيل

```sh
tools/visual/run.sh                                   # كل السيناريوهات × كل المقاسات
tools/visual/run.sh --scenario=p6-d3-shin-seen        # سيناريو واحد
tools/visual/run.sh --only=1352x672                   # مقاس واحد
tools/visual/run.sh --no-shots                        # قياس فقط (أسرع)
tools/visual/run.sh --list                            # عرض المتاح
tools/visual/run.sh --scale=2                         # لقطات بدقة مضاعفة (Retina)
```

اللقطات تُكتب في `tools/visual/out/<اسم-السيناريو>__<العرض>x<الارتفاع>.png`
وهذا المجلد مستثنى من git.

## المتطلبات

- نظام macOS مع **Brave Browser** (مبني على Chromium). لمسار آخر:
  `BRAVE_BIN="/path/to/Chromium" tools/visual/run.sh`
- `node` — يُستعمل المحرّك المرفق تلقائياً، ويمكن تعيينه عبر `NODE_BIN=...`.
- **لا يُثبَّت أي شيء، ولا يفتح المتصفح نافذة**: يعمل في وضع headless ببروفايل
  معزول داخل `.tools/` ويُحذف بعد كل تشغيل.

## كيف يعمل

1. يُشغّل المتصفح بلا واجهة عبر CDP (Chrome DevTools Protocol) بلا وسائط.
2. لكل مقاس: يضبط أبعاد النافذة، يفتح صفحة الدرس، **يفرّغ التقدّم المحفوظ**
   (وإلا ظهرت نافذة «هل تستكمل الحصة؟» ولطّخت اللقطات)، ثم ينفّذ خطوات السيناريو.
3. الخطوات تسلك **مسار المعلم الحقيقي**: نقر فعلي على أزرار الواجهة أو مفتاح حقيقي
   عبر خط إدخال المتصفح — لا استدعاء داخلي متجاوز للواجهة.
4. يُشغّل الفحوص العددية، ثم يلتقط PNG بمقاس CSS الدقيق المطلوب.
5. يفشل التشغيل (رمز خروج ≠ 0) إذا فشل أي فحص، فلا تمرّ عثرة بصمت.

## اللقطة وحدها لا تكفي

الفحص العددي يمنع «النجاح الكاذب» الذي تسبّبه اللقطة وحدها. القياسات تُقرأ من
المتصفح نفسه بعد استقرار إطارَي رسم:

- **اقتطاع نص رأسي**: `scrollHeight > clientHeight` للكبسولة (يكشف انضغاط عنصر
  مرن داخل بطاقة `overflow: hidden` — وهو ما لا يكشفه قياس الصندوق).
- **اقتطاع نص أفقي**: `scrollWidth > clientWidth`.
- **خروج العنصر عن منطقة البطاقة**: مقارنة إحداثيات الكبسولة بصندوق حشو البطاقة
  (منطقة القصّ الفعلية)، مع تمييز التجاوز الشعري (أقل من 2px) **كتنبيه** لا كفشل.
- **تراكب الحرف مع الكبسولة**، وخروج البطاقات أفقياً، و`overflow-x` للصفحة.
- **فحص مدمج دائم**: أي طبقة تحجب الشاشة (نافذة استكمال، شاشة انتباه، لوحة معلم)
  تُبطل القياس كله بدل أن تمرّ لقطة مشوّهة بصمت.

## ضبط السيناريوهات

كل شيء في `tools/visual/scenarios.json`:

```json
{
  "name": "p6-d3-shin-seen",
  "title": "وصف يظهر في المخرجات",
  "url": "lecture.html?lesson=03",
  "steps": [
    "goToPhase(5)",
    { "click": ".p6-reveal-btn" },
    { "clickText": { "sel": ".p6-round-btn", "text": "الأصوات المتقاربة" } },
    { "key": "Space" }
  ],
  "checks": [
    { "name": "وصف الفحص", "js": "(() => ({ pass: true, detail: 'ملاحظة' }))()" }
  ]
}
```

أنواع الخطوات: نص حر (JS يُنفَّذ في الصفحة) · `click` (محدّد CSS) ·
`clickText` (أول عنصر يحتوي النص ضمن محدّد) · `key` (`Space` · `Enter` ·
`ArrowLeft` · `ArrowRight`).

الفحص يُعيد `{ pass, detail }`، ويمكنه إعادة `warn: true` للحالات الشعرية.
و`blockers` في أعلى الملف يحدّد الطبقات التي تُبطل القياس.

## تشخيص سريع بقيمة مرجوعة

```sh
tools/visual/run.sh --scenario=p6-d3-shin-seen --only=1352x672 --no-shots \
  --probe='JSON.stringify(document.querySelector(".p6-d3-reveal-card").getBoundingClientRect())'
```

يطبع القيمة المُعادة تحت سطر `🔍 probe:` — مفيد لقياس هندسة أي عنصر قبل تعديله.
